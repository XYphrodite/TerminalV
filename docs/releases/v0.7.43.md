# TerminalV v0.7.43 — скролл mimo и отзывчивая прокрутка на телефоне

- **Скролл mimo заработал** (TUI с mouse tracking): вертикальный тач превращается в xterm wheel events (DOM_DELTA_LINE). xterm сам маршрутизирует их в SGR mouse reports (`\x1b[<65;…M`) для TUI или в стрелки для alt-buffer без мыши. Раньше тач только крутил DOM — TUI не получал wheel и не прокручивался вообще. Fling после касания продолжает слать wheel.
- **Обычный скролл стал плавным**: вертикальная прокрутка зеркала всегда на JS с fling-инерцией. Android WebView не умеет нативно скроллить CSS-zoomed поддерево (зум вписывает десктопную сетку в экран телефона) — из-за этого были рывки. Свои touch-обработчики xterm отрезаны через stopPropagation, чтобы не дублировать прокрутку.
- **Диагональный свайп больше не блокирует вертикаль**: на широкой сетке лёгкий наклон пальца захватывал ось X и убивал вертикальную прокрутку («иногда скрол не проходит»). Теперь на горизонталь нужно явное преимущество `|dx| > |dy| × 1.35`.
- Debug-хук `window.__tvTabs` для CDP-тестов живёт только в dev-сборке (`import.meta.env.DEV`); из продакшен-бандла вырезается минификатором.
- `copy-mobile-ui.js` перестал копировать в мобильный `wwwroot` мусор от прошлых сборок: папка ассетов пересобирается с нуля (было 43 файла ~15.7 МБ, стало 2).
- Тесты: `mirror-viewport` (4, включая wheel-путь), браузерные mirror/scroll/mobile. Весь прогон — 360/360.
- Видимая версия Android совпадает с Windows: **0.7.43**. VersionCode 39.

Для полной синхронизации нужны **Windows 0.7.43** и **TerminalV Mobile 0.7.43** (VersionCode 39).
