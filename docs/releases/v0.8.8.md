# TerminalV v0.8.8 — JSON null hardening

Релиз: `add-extension` и загрузка расширений не падают с `The requested operation requires an element of type 'Number', but the target element has type 'Null'.`

- Манифест расширения парсится вручную через `JsonDocument`.
- `NullToDefaultConverter` для `int`/`long`/`double`/`bool`: JSON `null` → default.
- `IncomingMessage.Cols/Rows` — `int?`; desktop и mobile bridges не падают на `cols: null`.
- Код выхода процесса читается только если это число.
- `add-extension` печатает полный stack trace.

```powershell
TerminalV update
TerminalV add-extension https://github.com/XYphrodite/TerminalV/releases/download/v0.8.8/terminalv.ai-limits.zip --replace
```
