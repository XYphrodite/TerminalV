# TerminalV v0.7.48 — облегчение мобильного клиента

Скролл зеркала сессии на бюджетных Android-устройствах был неюзабельно тяжёлым. В этом релизе — серия оптимизаций мобильного интерфейса.

- **Canvas-рендер вместо DOM** на телефоне: сетка терминала рисуется холстом, а не тысячами DOM-узлов. Это главный источник лагов при прокрутке на слабых GPU.
- **Прокрутка пальцем без рывков**: положение полосы обновляется не чаще одного раза за кадр, а не на каждое движение пальца. Fling-инерция сохранена.
- **Реже автосохранение снапшотов** на мобильных (раз в 5–15 секунд вместо 0.4–2 с): сериализация большого буфера больше не грузит процессор во время стриминга вывода. Офлайн-снимки сессий на месте.
- **Мигание курсора выключено** на телефоне — убирает постоянные перерисовки в простое.
- Диагностический watchdog (250 мс) на мобильных отключён — меньше фоновой работы.

Замер до/после на эмуляторе (8 свайпов, 800 строк вывода, `dumpsys gfxinfo`):

| Метрика | Было | Стало |
|---|---|---|
| Janky frames (legacy) | 10.0% | **4.4%** |
| Самый тяжёлый кадр (p99) | 105 ms | **32 ms** |
| Slow UI thread | 12 | **5** |
| Slow issue draw commands | 213 | **183** |

Медиана кадра упирается в вертикальную синхронизацию (60 fps) — выигрыш в «хвосте»: именно долгие кадры создают ощущение «телефон виснет». На слабом GPU реальный эффект заметнее, чем на эмуляторе.

Тесты: 385/385 UI, включая обновлённые фикстуры мобильного прогона. Видимая версия Android совпадает с Windows: **0.7.48**. VersionCode 44.

Для полной синхронизации нужны **Windows 0.7.48** и **TerminalV Mobile 0.7.48** (VersionCode 44).
