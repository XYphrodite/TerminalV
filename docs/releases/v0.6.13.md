# TerminalV v0.6.13 — окно держит минимальный размер

## Исправлено

- Окно можно было сузить ниже `MinWidth/MinHeight` (800×480): наш хук `WM_GETMINMAXINFO` выставлял только максимум и молча ронял штатный минимум WPF. Вёрстка с фиксированным сайдбаром разваливалась — элементы вылезали за край, правая часть терминала пропадала.
- Теперь `WindowFrame` выставляет `ptMinTrackSize` из `MinWidth/MinHeight` с пересчётом под DPI (`ComputeMinTrackSize`, масштаб читается свежим при каждом вызове — перетаскивание между мониторами не ломается). Окно упирается в 800×480 (×масштаб) и дальше не идёт.

## Проверки

- Windows-сборка и прогон в этой среде не запускались (`dotnet` недоступен) — сборка идёт через GitHub Actions при публикации тега. Приёмка: потянуть окно меньше 800×480 не получается.
