# TerminalV v0.5.8

## Быстрая вставка даже 100 символов в Muse

- `v0.5.6` резал только большие `>4000` вставки — для 100 символов с диалогом (`\n` → `showModal` → `term.paste`) чанкинг не срабатывал, `TerminalBridge.Handle("write")` и `ConPtySession.Write` всё ещё блокировали UI-поток WebView2 на `NamedPipe`/`FileStream` пока `muse` (Ink TUI) в `alternate buffer` не дренирует вход.
- Теперь `postWrite` в `ui/src/main.js` шлёт каждый чанк через `queueMicrotask` — `xterm` `triggerDataEvent` (вызванный из `term.paste` в диалоге) возвращается сразу, не ждёт `WriteFile` в ConPTY. Даже 100 символов с `\n` (1 чанк) не блокирует ввод.
- `TerminalBridge.Handle("write")` обёрнут в `Task.Run` — `WebMessageReceived` (UI thread) не блокируется на `SessionClient.Send`/`ConPtySession.Write`, `muse` может обрабатывать `ESC[200~...ESC[201~` без фриза сайдбара/пайпов.
- `ConPtySession.Write` теперь асинхронная очередь: `Enqueue(chunks) → Task.Run(ProcessWriteQueue)` — `lock(_writeGate)` держится только на `Enqueue/Dequeue`, реальный `StreamWriter.Write(chunk)` идёт в фоне последовательно, `Dispose`/`Resize` не режутся. `Dispose` чистит очередь, `ProcessWriteQueue` ловит `IOException`/`ObjectDisposedException`.
- Клавиатурный ввод (1 символ) и OSC `9;9` не затронуты. Профили/WSL/`SessionClient 4000` остались.

## Обновление

Выполните `TerminalV update` или нажмите **Обновить** в приложении. Для ручной установки — self-contained ZIP `win-x64`.

Перезапуск хоста не нужен, достаточно перезапуска окна.

- `TerminalV.Data.Tests` — 11 SQLite.
- `TerminalV.Shell.Tests` — 9 ярлыков.
- `installer-shortcuts.tests.ps1` — 8.
- `ui` — `node --test tests/*.test.js` с `TERMINALV_TEST_APP_ROOT=payload/wwwroot`: 186 Node/браузерных (180+6 `write-chunk.test.js` — добавлен `100 chars with dialog via microtask`).

Итого: `186 + 33 + 11 + 21 + 9 + 8 = 268` без пропусков при `TERMINALV_TEST_PWSH`/`WSL`/`CODEX_PATH`. Оба запускателя — `0.5.8`.

Пакет после сборки:

```powershell
.\scripts\publish.ps1 -OutputDirectory artifacts/release-v0.5.8
.\scripts\verify-package.ps1 -Package artifacts/release-v0.5.8/TerminalV-win-x64.zip
```

Ожидаемо: `TerminalV-win-x64.zip` (~66 МБ) + `.sha256` рядом, логи `verification-*` внутри каталога пакета.
