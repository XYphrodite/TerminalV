# TerminalV v0.6.2 — ресайз без задержки

## Исправлено

- Ресайз окна/панелей обновлял содержимое с задержкой ~80ms: `scheduleFit` использовал фиксированный `setTimeout 80ms` для `ResizeObserver` окна и перетаскивания разделителя. Теперь — `requestAnimationFrame` (≈16ms) с коалесценцией, fallback `16ms` в Node-тестах. `applyFit` логирует `fit applyFit ms`.
- Починён `diag is not defined` в UI-фиксах: `diag()` вынесен в глобальную область `main.js` (раньше был внутри `createTab`, `applyFit` падал).
- Порог `ignoreFitUntil` теперь проверяется внутри `applyFit`, а не удлинением таймера.

## Проверки

- `ui/tests` — **198/198 pass** (+2 новых `resize.test.js`: окно фитится за 35ms, rAF коалесцирует).
- `dotnet build src/TerminalV -c Release` — 0 ошибок.
