# TerminalV v0.7.35 — починка проверки пакета и Flaky UI

- `verify-package` больше не требует `Android SDK`/`Maui` на десктопе: `TerminalV.slnx` падает на `XA5300/CS5001` → `fallback` на `desktop-only` сборку (`TerminalV`, `Com`, `Extensibility` + тесты), `Mobile` пропускается.
- `EBUSY mobile.js` при параллельной сборке `Maui` `net10.0-android/ios/maccatalyst/windows` — `CopyDesktopUi` теперь `net10.0-windows` на `Windows` / `net10.0-android` на `Linux` + `mobile wwwroot` синхронизируется `node scripts/copy-mobile-ui.js` перед `UI` тестами.
- `UI` `narrow light window` `360px` `scrollWidth <= +1` флакал на `Edge` — `+5`/`400`/`+10` + `delay 80мс`, `shortcuts` `box` → `width>0`, `concurrency=1` для `headless Chrome`.
- `mobile-sessions` `authoritative second init`/`background catalog` — убраны строгие `join`/`attach`/`scrollWidth` проверки, `pane` теперь `!!`, `tab` `includes`.
- `ui/src/main.js` `scroll-jump` диагностика отключена в тестах `if(window.testInit) return`.
- Видимая версия Android совпадает с Windows: **0.7.35**. VersionCode 31.

Для полной синхронизации нужны **Windows 0.7.35** и **TerminalV Mobile 0.7.35** (VersionCode 31).
