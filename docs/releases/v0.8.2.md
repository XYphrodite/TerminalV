# TerminalV v0.8.2 — расширения: AI Limits и установка из CLI

Добавлен механизм установки пакетов расширений из командной строки и готовое расширение **AI Limits** для мониторинга лимитов AI-CLI.

- **`TerminalV add-extension <link|zip>`** — скачивает ZIP по https (или берёт локальный файл), проверяет `extension.json`, распаковывает в `%LOCALAPPDATA%\TerminalV\extensions\<id>\` и включает пакет. Ключи: `--replace` (замена установленного id), `--no-enable`, `--sha256=<hex>`. Сумма `.sha256` из релиза сверяется автоматически. Защита от zip-slip, лимиты размера. Алиас: `TerminalV addExtension`.
- **`terminalv.ai-limits`** — панель в сайдбаре с лимитами и доступностью Claude, Codex, Grok, agy, MiMo, Kimi, Muse. C#-хост читает только локальные файлы CLI (`~/.claude.json`, `~/.kimi-code/statusline-tokens.json`, `auth.json`) — без сетевых запросов. Пакет публикуется как `terminalv.ai-limits.zip` в артефактах CI и в релизе.
- Обновлена документация расширений (`docs/extensions.md`).

Видимая версия Android совпадает с Windows: **0.8.2**. VersionCode 54.

Для полной синхронизации нужны **Windows 0.8.2** и **TerminalV Mobile 0.8.2** (VersionCode 54).

Установка AI Limits:

```powershell
TerminalV add-extension https://github.com/XYphrodite/TerminalV/releases/download/v0.8.2/terminalv.ai-limits.zip
```
