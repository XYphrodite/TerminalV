# TerminalV v0.7.45 — обновление мобильного приложения прямо из приложения

- **Встроенные обновления на Android**: кнопка версии в мобильном приложении теперь проверяет GitHub Releases и ставит новую версию без похода на сайт. Приложение само скачивает APK, сверяет SHA256 и запускает системный установщик — остаётся один тап «Установить» в системном окне.
- Контрольная сумма обязательна: несовпадение или отсутствие sidecar-файла запрещает установку. Репозиторий и имя ассета зашиты в код — подмена источника невозможна, как и на десктопе.
- FileProvider отдаёт установщику только файлы из кэша `updates/`, провайдер не экспортируется.
- UI: кнопка версии на мобильном активна при поддержке обновлений, статус «скачано — подтвердите установку в системном окне» (Android не умеет ставить APK молча).
- Исправлено: статический конструктор загрузчика падал на User-Agent со слэшем, из-за чего мобильное приложение молча теряло `app-info` и кнопка версии висела на «…».
- Тесты: весь прогон — 369/369. Сборка Android без ошибок.
- Видимая версия Android совпадает с Windows: **0.7.45**. VersionCode 41.

Для полной синхронизации нужны **Windows 0.7.45** и **TerminalV Mobile 0.7.45** (VersionCode 41).
