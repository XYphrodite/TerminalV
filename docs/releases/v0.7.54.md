# TerminalV v0.7.54 — телефон задаёт размер сессии, без горизонтального скролла

- **Горизонтального скролла на телефоне больше нет.** Широкая сетка с десктопа (Kimi, TUI) больше не уезжает вбок: если сетка шире экрана, она ужимается по ширине. Панорамирование пальцем влево-вправо убрано — остаётся только вертикальный скролл истории.
- **Телефон задаёт размер сессии.** При подключении к ПК сетка строится по экрану телефона, а не по размеру окна десктопа. Повороты и изменения размера подстраивают терминал автоматически.
- Режим «Подстраивать размер сессии под телефон» теперь включён по умолчанию.

Видимая версия Android совпадает с Windows: **0.7.54**. VersionCode 50.

Для полной синхронизации нужны **Windows 0.7.54** и **TerminalV Mobile 0.7.54** (VersionCode 50).
