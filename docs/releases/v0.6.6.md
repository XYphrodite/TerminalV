# TerminalV v0.6.6 — паузы между чанками вставки

## Исправлено

- Паузы «мб между чанками большие» на `0.6.5` при вставке 5К и больше: `postWrite` делал `queueMicrotask` на **каждый** чанк `4000` (2-13 микрозадач), между чанками была видимая пауза «сначала одна, потом вторая». Теперь один `queueMicrotask` батчит все чанки `for(... ) post(write)` — 1 микрозадача + `await`, `Diag` уже асинхронный батч 50.
