# TerminalV v0.7.17 — кириллица на телефоне и полировка мобильного терминала

- Мобильный терминал `1.1.7`: исправлен ввод кириллицы с Gboard — изолированный `terminal.js` теперь `allowProposedApi:true` и тот же стек `Roboto Mono`/`Droid Sans Mono`/`Noto Sans Mono` + `letterSpacing:0`, вставка `Привет` и набор `привет`/`йцукен` уходят как UTF-8 через `onData` → `WriteAsync`.
- Сохранены все правки `0.7.16`: телефон не меняет размер PTY на ПК, сетка символов синхронизируется перед историей, клавиатура/поворот/панель сессий трогают только видимую область.
- Для полной синхронизации нужен **TerminalV Mobile 1.1.7** (VersionCode 13).
