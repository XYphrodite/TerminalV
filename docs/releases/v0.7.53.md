# TerminalV v0.7.53 — заголовок окна наконец «TerminalV»

- **Заголовок окна и системные диалоги показывают текст, а не ключи.** Фикс из 0.7.51 не до конца решал проблему: на некоторых сборках фабрика локизации всё равно не находила ресурс, и в шапке окна снова отображалось `Window_Title`. Теперь строки берутся из ресурса по точному имени (`TerminalV.Localization.Resources.Strings`) — результат не зависит от разбора путей поиска.

Видимая версия Android совпадает с Windows: **0.7.53**. VersionCode 49.

Для полной синхронизации нужны **Windows 0.7.53** и **TerminalV Mobile 0.7.53** (VersionCode 49).
