# TerminalV v0.7.29 — одна версия на ПК и Android

- Видимая версия Android совпадает с Windows: **0.7.29**. Раньше телефон показывал отдельную линейку 1.1.x.
- Служебный VersionCode Android стал 25. Это целое число для установки поверх прошлого APK; в интерфейсе оно не показывается.
- Сборка релиза проверяет, что `ApplicationDisplayVersion` равен `Version` в проекте ПК.

Для полной синхронизации нужен **TerminalV Mobile 0.7.29** (VersionCode 25).
