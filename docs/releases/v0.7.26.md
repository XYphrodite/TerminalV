# TerminalV v0.7.26 — клавиатура как на клавиатуре + красивый вид + Alt+Enter перенос

- Вкладка клавиш теперь **как на клавиатуре** (Variant A): `Row1 Esc·F1-F12`, `Row2 1-0`, `Row3 Tab·Home/End/PgUp/PgDn/Ins/Del`, `Row4-5 Ctrl + ↵(Alt+Enter) + стрелки Т-формой` — 5 рядов, каждый `flex nowrap + overflow-x:auto`, ручка `Клавиши` по центру.
- **Красиво**: панель `#0f141c` с тенью `0 -8px 24px`, клавиши-чиклеты `linear-gradient #1e2736→#171d26`, `border #253141`, `shadow inset + 0 2px 4px`, `active` вдавливание, `Ctrl.active` синий, `↵` — синий акцент `#1e3a5f/#2a5a8a`, `spacer` для Т-формы.
- **Перенос строки**: новая кнопка `↵` шлёт `Alt+Enter`=`\x1b\r` универсально (Enter=`\r` — отправка сообщения у агентов, `Alt+Enter` — перенос; для разных сессий/агентов можно расширить маппинг `sessionId → последовательность`).

Для полной синхронизации нужен **TerminalV Mobile 1.1.16** (VersionCode 22).
