# TerminalV v0.6.0 — MAUI мобильный SSH-клиент

## Лёгкий MAUI Blazor Hybrid

- Новый проект `src/TerminalV.Mobile` (`net10.0-android;net10.0-ios;net10.0-maccatalyst;net10.0-windows10.0.19041.0`, `UseMaui`, `BlazorWebView`): `MauiProgram.cs`, `App.xaml`, `MainPage.xaml`, `wwwroot/js/terminal.js` (xterm.js 5.5 + fit/search/web-links), `Home.razor`.
- `WPF` (`src/TerminalV`) остаётся fallback для локального `ConPTY` — MAUI не заменяет его, а дополняет для мобильных.

## Двойной коннектор, только shell

- **Прямо к `sshd`** — `SshNetSession.cs` (`SSH.NET` `SshClient` + `ShellStream` `xterm-256color`, `cols/rows`, `WriteAsync`/`Resize`, `AutoReconnect`).
- **Через шлюз `TerminalV`** — `GatewaySshSession.cs` (`ClientWebSocket` + JSON handshake `{host,port,username,password,privateKey,cols,rows,term}`, binary `data` + `resize`).
- Общий `SshSessionBase`/`ISshSession`/`SshConnectionOptions`/`SshService` (выбор по `UseGateway`), `WPF` и `Mobile` могут шарить `Ssh` папку.
- `Components/Terminal.razor` + `wwwroot/js/terminal.js` — `create(id,cols,rows)` / `write(id,data)` / `onData -> postMessage/DotNet.invokeMethodAsync`.

Добавлен в `TerminalV.slnx` → `/src/TerminalV.Mobile`.

## Обновление

`dotnet workload install maui` (один раз) затем `dotnet build -f net10.0-windows10.0.19041.0` или `dotnet build` для Android/iOS. `WPF` собирается как раньше (`EnableWindowsTargeting` на Linux).

Пакет пока без отдельного установщика — `Mobile` собирается из `src/TerminalV.Mobile`.

## Проверки

- `dotnet build -p:EnableWindowsTargeting=true` (WPF) — `wwwroot` + `Ssh` без `MemoryStream` ошибок (добавлен `System.IO`).
- `npm run build` (Vite) — `wwwroot` 504kB.
- `Mobile` — `wwwroot/js/terminal.js` содержит `WebLinksAddon`, `term.onData`, `window.TerminalV.write`.
- `Ssh` — `SshNetSession`/`GatewaySshSession` покрывают `host/port/user/auth` + `xterm-256color`.

Пакет `win-x64` для `WPF` собирается как раньше; `Mobile` — `apk/ipa` отдельно.
