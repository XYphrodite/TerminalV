# TerminalV v0.7.49 — прогресс-бар обновления и устойчивое скачивание на Android

- **Полоса прогресса при скачивании обновления**: в полосе обновления в сайдбаре видно процент загрузки («Скачивание обновления… 43%»). Если размер файла неизвестен — аккуратная бегущая анимация. После загрузки показывается «Проверка обновления…», затем «Установка обновления…». Работает и в Windows-клиенте, и в мобильном приложении — прогресс пробрасывается из загрузчика в интерфейс.
- **Мобильное обновление больше не падает с «unexpected end of stream»**: Android-стек HTTP обрывает длинные ответы (keep-alive, CDN GitHub). Теперь такие обрывы автоматически повторяются до трёх раз, усечённая загрузка APK определяется по Content-Length и тоже перезапускается. Если сеть действительно недоступна, показывается понятное сообщение по-русски, а не сырой текст библиотеки.
- i18n: добавлены подписи фаз обновления; отсутствовавший ключ «Установка обновления…» больше не вываливается в интерфейс сырым идентификатором.
- Тесты: 6 проверок логики прогресса и 8 проверок политики ретраев мобильного загрузчика. Весь прогон UI — 391/391.

Видимая версия Android совпадает с Windows: **0.7.49**. VersionCode 45.

Для полной синхронизации нужны **Windows 0.7.49** и **TerminalV Mobile 0.7.49** (VersionCode 45).
