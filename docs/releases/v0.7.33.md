# TerminalV v0.7.33 — ANR и скрытые сессии на Android

- Исправлен ANR `Input dispatching timed out` при нажатии «Новая вкладка». `SshService.ConnectAsync` (DNS/Tailscale/WebSocket `GatewaySshSession` до 10с) теперь выполняется в `Task.Run` вне UI-потока, `Resize` через `ConfigureAwait(false)`.
- Исправлена потеря вкладок после `force-stop` на Android. Когда шлюз недоступен (`connectionError != null`), кэшированные сессии без буфера больше не фильтруются по `liveSet` — `Скрытые · 5` сохраняются вместо `0`.
- Видимая версия Android совпадает с Windows: **0.7.33**. VersionCode 29.

Для полной синхронизации нужны **Windows 0.7.33** и **TerminalV Mobile 0.7.33** (VersionCode 29).
