# TerminalV v0.5.12

## Кнопка управления сессией всегда видна

- Ранее `⋯` (Управление сессией) имела `opacity:0` и показывалась только на `hover/active/focus-within` (`styles.css`). В плотном списке без ховера казалась пропавшей.
- Теперь `chrome.css` переопределяет `opacity:1` для `.tab-close, .tab-options` в развёрнутом сайдбаре; в свёрнутом (`#app.collapsed`) остаётся `display:none` как и раньше (места нет).

## Обновление

`TerminalV update` или ZIP `win-x64`. Совместимо с 0.5.11, хост не перезапускается.
