# TerminalV v0.5.4

## Новая иконка

- Голубая геометрическая **V с курсором `_`** на графитовом фоне вместо синей плитки с чёрной V.
- Единая иконка для EXE, окна и заголовка приложения.
- Девять 32-битных размеров ICO: 16, 20, 24, 32, 40, 48, 64, 128 и 256 пикселей. Курсор выровнен по пикселям для чёткости в маленьком размере.
- Генератор `scripts/make-icon.ps1` поддерживает `-PreviewPath` для проверки на светлом и тёмном фоне.

Изменение только визуальное: ввод, вывод, копирование, вставка, настройки и рабочие сессии не меняются.

## Обновление

Выполните `TerminalV update` или нажмите **Обновить** в приложении. Для ручной установки доступны self-contained ZIP для Windows x64 и файл SHA-256.

Для новой иконки достаточно обновить приложение и заново открыть его окно; перезапуск фонового host для этого изменения не нужен. Установленное приложение и рабочие сессии при подготовке релиза не затрагивались.

## Проверки и пакет

Релизный ZIP прошёл 234 проверки без пропусков: 171 Node/браузерную, 31 PTY/транспортную, 11 SQLite и 21 проверку пакета/CLI/изолированного обновления. Проверены PowerShell 5.1 и 7, cmd, обнаружение установленного Codex при старом PATH и установленная Ubuntu. Оба запускателя возвращают `0.5.4`; версия продукта в свойствах EXE — `0.5.4`.

Дополнительно проверены все девять кадров ICO через WPF-декодер и новая иконка, извлечённая из EXE распакованного релизного архива. Превью просмотрено на светлом и тёмном фоне в реальных маленьких размерах.

Браузерные app-fixtures загружали интерфейс из распакованного ZIP. Ручная проверка WPF/WebView2-окна и отображения иконки в панели задач в отдельной Windows-среде не проводилась. Рабочий host, установленное приложение и пользовательская база не затрагивались; обновление проверялось на временных копиях через локальный источник релиза.

Release-сборка решения успешна, без ошибок и предупреждений MSBuild. Неблокирующие сообщения: npm allow-scripts для esbuild и Vite о JS-бандле немного больше 500 kB.
