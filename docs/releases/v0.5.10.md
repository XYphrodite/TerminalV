# TerminalV v0.5.10

## Ссылки в терминале — во внешнем браузере

- Ранее клик по URL в выводе (`@xterm/addon-web-links` + OSC 8) вызывал `window.open()` внутри WebView2 — открывалось встроенное окно/пустая страница.
- Теперь `ui/src/main.js` перехватывает оба источника: `WebLinksAddon` с кастомным хэндлером `(event, uri) => handleLink` и `Terminal.linkHandler.activate` для OSC-ссылок. Хэндлер валидирует `new URL(uri)` → только `http:`/`https:` и отправляет `post({type:"open-link", uri})`.
- Хост `Host/TerminalBridge` принимает `open-link`, повторно валидирует `Uri.TryCreate` + схема, открывает через `Process.Start(new ProcessStartInfo(parsed.AbsoluteUri){UseShellExecute=true})` на UI-потоке, при ошибке показывает `MessageBox`.
- `MainWindow` страхует встроенный `window.open`: `CoreWebView2.NewWindowRequested` (обрабатывает и открывает внешне) и `NavigationStarting` (всё кроме `https://terminalv.local` / `https://tvdata.local` отменяется и уходит в браузер). Это покрывает любой оставшийся путь, не идущий через JS-хэндлер.
- `Host/IncomingMessage.Uri` добавлен для десериализации `uri`.

## Обновление

Выполните `TerminalV update` или нажмите **Обновить** в приложении. Для ручной установки — self-contained ZIP `win-x64`.

Перезапуск хоста не нужен, достаточно перезапуска окна. Совместимо с настройками/сессиями 0.5.9.

- `dotnet build -c Release` — 0 ошибок, `BuildUi` (Vite) успешно.
- `TerminalV.Package.Tests` — 21 ZIP/CLI/обновление-откат.
- `TerminalV.Pty.Tests` — 33 проверки.
- `TerminalV.Data.Tests` — 12 SQLite.
- `TerminalV.Shell.Tests` — 9 ярлыков.
- `installer-shortcuts.tests.ps1` — 8.
- `ui` — `node --test tests/*.test.js` с `TERMINALV_TEST_APP_ROOT=payload/wwwroot`: 186 Node/браузерных.

Итого: `186 + 33 + 12 + 21 + 9 + 8 = 269` без пропусков. Оба запускателя — `0.5.10`.

Пакет после сборки:

```powershell
.\scripts\publish.ps1 -OutputDirectory artifacts/release-v0.5.10
.\scripts\verify-package.ps1 -Package artifacts/release-v0.5.10/TerminalV-win-x64.zip
```

Ожидаемо: `TerminalV-win-x64.zip` (~66 МБ) + `.sha256` рядом, логи `verification-*` внутри каталога пакета.
