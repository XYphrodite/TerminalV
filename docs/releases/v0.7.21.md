# TerminalV v0.7.21 — выдвижная клавиатура + все клавиши

- Нижняя панель с клавишами теперь **выдвижная** (занимала место): скрыта по умолчанию (`translateY(100%)`), выезжает по тапу на ручку `#mobile-keys-handle`, скрывается тапом вне панели, экономит экран. Ручка `68×28px` сверху панели.
- Расширены клавиши в `MOBILE_KEY_SEQUENCES`: `Home \x1b[H` / `End \x1b[F` / `PageUp/PgUp \x1b[5~` / `PageDown/PgDn \x1b[6~` / `Delete/Del \x1b[3~` / `Insert/Ins \x1b[2~` / `F1 \x1bOP F2 \x1bOQ F3 \x1bOR F4 \x1bOS F5 \x1b[15~ F6 \x1b[17~ F7 \x1b[18~ F8 \x1b[19~ F9 \x1b[20~ F10 \x1b[21~ F11 \x1b[23~ F12 \x1b[24~` / `Ctrl+←→↑↓ \x1b[1;5D/C/A/B` (алиасы `Ctrl+Left` и т.д.). `Ctrl` — sticky-toggle (одно нажатие удерживает для следующей клавиши).
- Портировано в `src/TerminalV.Mobile/wwwroot` (`css/app.css`, `js/terminal.js`, `index.html`) для Android MAUI.

Для полной синхронизации нужен **TerminalV Mobile 1.1.11** (VersionCode 17).
