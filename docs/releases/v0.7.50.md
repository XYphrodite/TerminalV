# TerminalV v0.7.50 — мобильные фиксы: завершение сессии и клавиатура

- **Сессию с телефона теперь можно завершить.** Подтверждение закрытия останавливает процесс на компьютере, а не только разрывает соединение телефона. Раньше вкладка исчезала и тут же возвращалась при следующем обновлении списка сессий.
- **Клавиатура больше не выскакивает при входе в сессию.** Тап по сессии в списке открывает терминал без IME; клавиатура появляется, только когда вы сами тапаете по сетке терминала. На Windows поведение прежнее.
- Проверено на Android-эмуляторе: авто-фокус и IME после входа в сессию отсутствуют, тап по терминалу открывает клавиатуру, закрытие сессии работает.
- Тесты: проверка авто-фокуса в мобильном UI и завершения десктопной сессии через гейтвей. Весь прогон UI — 392/392.

Видимая версия Android совпадает с Windows: **0.7.50**. VersionCode 46.

Для полной синхронизации нужны **Windows 0.7.50** и **TerminalV Mobile 0.7.50** (VersionCode 46).
