# TerminalV v0.8.25 — точечные сплиты и свободная перестановка панелей как в VS Code

- **Разделение именно выбранной панели и 2D-сетки:** кнопки «Справа» / «Снизу» (`Alt+Shift+=` / `Alt+Shift+-`) теперь всегда делят только сфокусированную панель — например, разделение правой панели вниз добавляет сессию строго под правой панелью, оставляя левую во всю высоту. Поддерживаются сетки `2×2` и любые вложенные комбинации до 8 панелей.
- **Быстрые действия в заголовках панелей:** в заголовке каждой разделённой панели появились компактные кнопки быстрого разделения вправо/вниз и отделения в самостоятельную вкладку.
- **Drag & Drop панелей и вкладок (как в VS Code):** перетаскивайте заголовок любой панели или сессию из левого списка на верхнюю, нижнюю, левую или правую часть нужной панели для стыковки, в центр — для мгновенного обмена местами с сохранением пропорций, к самому внешнему краю окна — для общей панели на всю ширину/высоту, либо обратно в список сессий — для отделения во вкладку (без перезапуска `ConPTY` и без потери истории вывода).

```powershell
TerminalV update
```
