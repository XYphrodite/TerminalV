# TerminalV v0.7.0 — обновление на общем kit + лёгкая установка

## Обновление

- Самообновление переведено на общий `SelfUpdateKit`: обязательный SHA-256 ZIP, проверка состава payload, probe с откатом, отложенное применение UI через pending-маркер. Поведение `TerminalV update` не изменилось.
- Лёгкий вариант: `publish.ps1` собирает `TerminalV-win-x64-light.zip` (framework-dependent), `install.ps1` ставит его при наличии .NET desktop runtime (`-Variant auto|full|light`), выбранный вариант записывается и `update` его держит.

## Проверки

- `dotnet build` 0 ошибок, `SelfUpdateKit` 77/77, `installer-variant` 8/8, `Package.Tests` компилируется (end-to-end — через `verify-package.ps1` в CI).
