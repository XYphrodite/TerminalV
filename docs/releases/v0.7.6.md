# TerminalV v0.7.6 — исправление прокрутки сессий

При возвращении в сессию после вывода в фоновую вкладку теперь можно прокрутить её до конца без нажатия клавиши ↓. Исправлено восстановление области прокрутки при первом показе сохранённого вывода и переключении панелей, в том числе когда размер терминала не меняется.

Позиция при чтении истории сохраняется. Переключение полноэкранных TUI не очищает историю обычной консоли.

Перед сборкой и публикацией GitHub Actions проверяет пять браузерных сценариев: фоновый вывод, первый показ восстановленной сессии, сохранение позиции в истории, быстрые переключения и альтернативный экран TUI.
