# TerminalV v0.7.51 — заголовок окна снова «TerminalV»

- **Исправлен заголовок окна**: вместо «TerminalV» показывался сырой ключ `Window_Title`. Причина — неверный путь поиска ресурсов локализации (`ResourcesPath`), из-за которого все строки WPF-интерфейса (заголовок окна, заголовки системных диалогов) отдавали свои ключи вместо текста. WebView-часть интерфейса не была затронута.
- Проверка пути поиска добавлена в набор тестов, чтобы регрессия не вернулась.

Видимая версия Android совпадает с Windows: **0.7.51**. VersionCode 47.

Для полной синхронизации нужны **Windows 0.7.51** и **TerminalV Mobile 0.7.51** (VersionCode 47).
