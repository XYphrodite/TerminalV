# TerminalV v0.7.55 — телефон главный в размере PTY

- **Телефон теперь действительно задаёт размер сессии.** Раньше шлюз отклонял resize от телефона для десктопных сессий: PTY оставался размера окна десктопа (например 182×42), телефон показывал широкую сетку, и TUI вроде Kimi уезжал вбок. Теперь resize телефона применяется, и пока телефон подключён, окно десктопа не откатывает сетку обратно.
- Сохранены исправления предыдущего релиза: без горизонтального скролла, вертикальный скролл истории работает.

Видимая версия Android совпадает с Windows: **0.7.55**. VersionCode 51.

Для полной синхронизации нужны **Windows 0.7.55** и **TerminalV Mobile 0.7.55** (VersionCode 51).
