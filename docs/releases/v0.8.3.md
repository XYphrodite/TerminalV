# TerminalV v0.8.3 — фикс add-extension

Патч к v0.8.2: `TerminalV add-extension` падал после загрузки ZIP с ошибкой «file is being used by another process».

- **`add-extension` закрывает `package.zip` до проверки SHA256.** Раньше поток записи оставался открытым, и checksum/распаковка не могли прочитать файл. Теперь загрузка, sidecar `.sha256` и установка работают по обычному сценарию:

```powershell
TerminalV add-extension https://github.com/XYphrodite/TerminalV/releases/download/v0.8.3/terminalv.ai-limits.zip
```

Функциональность v0.8.2 (AI Limits, `add-extension`) без изменений. Mobile/Mirror — **0.8.3** (VersionCode 55).

Для полной синхронизации нужны **Windows 0.8.3** и **TerminalV Mobile 0.8.3** (VersionCode 55).
