# TerminalV v0.5.9

## Сохранение видимых сессий

- Ранее `Buffer`/`Cwd` надёжно переживали перезапуск только для скрытых сессий (`Скрыть, оставив работать`). Видимая вкладка после перезапуска Windows/хоста показывала пустой чат.
- Теперь `AppDatabase.SaveSessions` хранит `Buffer`/`Cwd`/`Group/Color/Pinned` для всех сессий независимо от `Hidden` — `Hidden` только про видимость вкладки и раскладку (`PaneLayout.Normalize` исключает скрытые из `layouts`, но не из `sessions`). `SessionRecord.Hidden` документирован.
- `ProjectContext.md`/`README.md` обновлены, `TerminalV.csproj` `Version=0.5.9`.

## Обновление

Выполните `TerminalV update` или нажмите **Обновить** в приложении. Для ручной установки — self-contained ZIP `win-x64`.

Перезапуск хоста не нужен, достаточно перезапуска окна. Старые скрытые сессии совместимы, видимые теперь тоже имеют снимок экрана.

## Проверки и пакет

Релизный ZIP должен пройти `scripts/verify-package.ps1`:

- `dotnet build -c Release` — 0 ошибок, `BuildUi` (Vite) успешно.
- `TerminalV.Package.Tests` — 21 ZIP/CLI/обновление-откат.
- `TerminalV.Pty.Tests` — 33 проверки.
- `TerminalV.Data.Tests` — 12 SQLite (11 прежних + `visible sessions preserve buffer and metadata without requiring hidden` — видимая `Buffer "привет чат история"` + `Cwd` + `Hidden=false`/`Active=true` переживают `Save/Load`, `hidden` тоже, `layouts` фильтруется).
- `TerminalV.Shell.Tests` — 9 ярлыков.
- `installer-shortcuts.tests.ps1` — 8.
- `ui` — `node --test tests/*.test.js` с `TERMINALV_TEST_APP_ROOT=payload/wwwroot`: 186 Node/браузерных.

Итого: `186 + 33 + 12 + 21 + 9 + 8 = 269` без пропусков при `TERMINALV_TEST_PWSH`/`WSL`/`CODEX_PATH`. Оба запускателя — `0.5.9`.

Пакет после сборки:

```powershell
.\scripts\publish.ps1 -OutputDirectory artifacts/release-v0.5.9
.\scripts\verify-package.ps1 -Package artifacts/release-v0.5.9/TerminalV-win-x64.zip
```

Ожидаемо: `TerminalV-win-x64.zip` (~66 МБ) + `.sha256` рядом, логи `verification-*` внутри каталога пакета.
