# TerminalV v0.8.20 — исправление вылета при выборе фонового изображения

- Устранён вылет (`0xc0000409` / конфликт Shell-расширений Проводника Windows 11 и `CETCompat` в `.NET 10`) при открытии системного диалога выбора фонового изображения сессии (`Настройки` → `Фон сессии` → `Выбрать`): диалог теперь запускается в изолированном дочернем процессе `--pick-background`, а для исполняемого файла отключён принудительный `CETCompat`.
- Исправлен порядок применения `allowTransparency` и `theme` для `WebGL`-рендерера терминала при установке и сбросе фонового изображения.

```powershell
TerminalV update
```
