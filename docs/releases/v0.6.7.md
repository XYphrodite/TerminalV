# TerminalV v0.6.7 — рваный верх TUI после ресайза

## Исправлено

- Верх сессии с `muse` выглядел рваным (`│re-...│`/`Totals` наслоение `Calling tools`) после ресайза окна/панелей. Причина — `applyFit` делал `term.refresh` без очистки WebGL-текстуры для `alternate buffer` (`tui-lock`). Теперь для `tui-lock` — `webgl.clearTexture()` + `term.refresh(0,rows-1,true)` (hard refresh только alternate-кадра), для обычного — как раньше. Скроллбэк (`normal buffer`) не трогается.
