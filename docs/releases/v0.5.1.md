# TerminalV v0.5.1

## Обновлённый дизайн

- Более читаемый список сессий: единые SVG-иконки, аккуратные отступы и выделение активной вкладки.
- Название сессии и текущая папка в заголовке рабочей области; длинный путь доступен целиком при наведении.
- Обновлённые панели, кнопки, диалоги подтверждения и предпросмотр многострочной вставки.
- Миниатюры десяти тем с отметкой выбранной; оформление элементов управления согласовано со светлой или тёмной темой.
- Компактный список сессий освобождает всю доступную ширину терминала, без пустого отступа слева. Панель инструментов адаптируется к узкому окну.
- Настройки удерживают фокус клавиатуры: `Tab` переключает элементы внутри панели, `Esc` закрывает её и возвращает фокус терминалу. Сочетания управления сессиями за открытыми настройками не выполняются.

Сохранённые темы, шрифты и сессии совместимы. Шрифт и цветовая схема самого терминала не заменяются. Иконки локальные: новые внешние ресурсы и зависимости не добавлены.

## Обновление

Выполните `TerminalV update` или нажмите «Обновить» в приложении. Для ручной установки доступны self-contained ZIP для Windows x64 и файл SHA-256.

При подготовке релиза установленное приложение и рабочие сессии пользователя не затрагивались. Ручная проверка WPF/WebView2 и обновления с открытыми окнами в отдельной Windows-среде не проводилась.

## Проверки и пакет

На релизном ZIP прошли все 206 автоматических проверок: 157 Node/браузерных, 18 PowerShell 5.1/7, cmd и ConPTY, 10 SQLite и 21 проверка пакета/CLI/изолированного обновления. Пропусков нет. Release-сборка решения завершена без ошибок и предупреждений MSBuild; npm выводит неблокирующее предупреждение allow-scripts для esbuild.

Браузерные app-fixtures загружали интерфейс из распакованного ZIP. Обновление проверялось на временных копиях через локальный источник релиза, без рабочего host pipe и пользовательской базы. `TerminalV.exe --version` и `TerminalV.com --version` вернули `0.5.1`.
