# TerminalV v0.8.21 — автоматический запуск от имени Администратора

- При запуске GUI `TerminalV.exe` теперь автоматически регистрирует флаг `~ RUNASADMIN` в `AppCompatFlags\Layers` и при отсутствии прав администратора перезапускает себя с повышением привилегий (`Verb = "runas"`), чтобы все открытые вкладки терминала работали с правами Администратора.
- При старте с правами Администратора `SessionClient` автоматически перезапускает ранее запущенный неповышенный фоновый процесс `TerminalV --host`, чтобы новые сессии `PowerShell` / `cmd` наследовали токен Администратора.
- Ярлыки `TerminalV.lnk` (Рабочий стол / меню «Пуск»), создаваемые через настройки приложения, теперь автоматически получают флаг `SLDF_RUNAS_USER` («Запуск от имени администратора»).

```powershell
TerminalV update
```
