# TerminalV v0.6.4 — вставка без «по строчке»

## Исправлено

- Вставка в `muse` шла «сначала одна, потом вторая» — по строчке с паузой. Причина: `Diagnostics/Diag.cs` делал синхронный `File.AppendAllText` под `lock` на каждый чанк `4000`/`8192` (paste → `SessionClient` → `ConPty`). На 50К это 13 чанков × 30-50ms блока = 400-600ms «печати». Теперь `Diag.Log` не блокирует горячий путь: `Debug.WriteLine` сразу, запись в файл — асинхронный батч-воркер `ConcurrentQueue` + `Task.Run(FlushQueue)` до 50 строк за `AppendAllLines`, `Interlocked` защита, ротация `5MB` осталась.

## Проверки

- `dotnet build -c Release` — 0 ошибок, `ui` 204/204 pass (включая `resize`/`session-restore`).
- `Pty concurrent 4K` — <2000ms, теперь быстрее за счёт отсутствия блока на логе.

`TerminalV update` или `scripts/publish.ps1`.
