# TerminalV v0.8.1 — UTF-8 в ConPTY-сессиях

Убран mojibake в выводе Python/CLI-агентов (например статус-бар Hermes): русский текст больше не приезжает кракозябрами вроде `РусСёрРIРµСЊСЃ`.

- **Сессии принудительно UTF-8.** В окружение каждой новой оболочки добавлены `PYTHONUTF8=1` и `PYTHONIOENCODING=utf-8`. Python больше не использует `cp1251` из `locale.getpreferredencoding()` для `open()` / `Path.read_text()` / `subprocess`.
- **PowerShell и cmd стартуют с `chcp 65001`**, консольные потоки — UTF-8. Нативные утилиты не пишут OEM-байты (CP866) в ConPTY-трубу.
- Host TerminalV не меняет пользовательские настройки — только окружение новой сессии.

Mobile-адаптация и resize PTY не были причиной: fit лишь перерисовывал TUI и проявлял баг писателя.

Видимая версия Android совпадает с Windows: **0.8.1**. VersionCode 53.

Для полной синхронизации нужны **Windows 0.8.1** и **TerminalV Mobile 0.8.1** (VersionCode 53).
