# TerminalV v0.8.5 — JSON null больше не роняет приложение

Патч к v0.8.4: ошибка `The requested operation requires an element of type 'Number', but the target element has type 'Null'.` могла появиться снова — `int?` для `apiVersion` не закрывал другие места.

- **Манифест расширения** парсится вручную через `JsonDocument`, а не через `JsonSerializer.Deserialize` — JSON `null` в любом числовом поле не крашит `add-extension` и загрузку пакета.
- **`NullToDefaultConverter`** для `int`/`long`/`double`/`bool` в настройках и сообщениях WebView: `null` трактуется как значение по умолчанию.
- `IncomingMessage.Cols/Rows` — `int?`, resize/create не падают на `cols: null`.
- `SessionClient` / `GatewaySshSession`: код выхода читается только если это число.
- `add-extension` печатает полный stack trace.

```powershell
TerminalV update
TerminalV add-extension https://github.com/XYphrodite/TerminalV/releases/download/v0.8.5/terminalv.ai-limits.zip --replace
```
