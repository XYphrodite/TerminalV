# TerminalV v0.5.11

## Порядок вкладок при разделении экрана

- Ранее кнопка **Справа** / **Снизу** (`Alt+Shift+=` / `Alt+Shift+-`, `splitSession`) создавала новую сессию, но `tabs.push(tab)` всегда добавлял её в конец списка слева. Новая вкладка оказывалась последней, а не рядом с родительской панелью.
- Теперь `ui/src/main.js` использует `insertAfter(tabs, tab, options.splitFrom)` — при `splitFrom` сессия вставляется сразу после родительской (`splice(idx+1,0,tab)`), иначе (`Ctrl+Shift+T`, `Новая вкладка`) — как и раньше в конец. Логика вынесена в `ui/src/session-management.js:insertAfter` и покрыта тестом.
- Группировка `sessionGroups` сохраняет порядок: новая сессия в той же группе оказывается соседней с родителем; для разных групп — соседней в сыром порядке `tabs` (отображение по группам может разнести, но сырой порядок сохранён).
- `pane-layout.js:splitSession` без изменений — раскладка уже создавала `second: {sessionId: newId}` рядом с родителем; теперь и список вкладок консистентен с раскладкой.
- Визуально дочерняя сессия отличается в сайдбаре: `chrome.css` добавляет `split-child` (отступ 16px + тонкая L-линия `::before/::after` из `var(--border-soft)`) и `split-parent` (точка под иконкой). Из `pane-layout.js:isSplitChild/isSplitParent` в `renderTabs`/`patchTabRow` ставятся классы, в свёрнутом сайдбаре отступ скрыт. Покрыто тестом `split child/parent are detectable`.
