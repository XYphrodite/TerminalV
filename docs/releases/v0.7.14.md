# TerminalV v0.7.14 — подключение мобильного клиента через Tailscale

Черновик описания выпуска. Сборка предназначена для передачи пользователю; публикация GitHub пока не выполнялась.

- Восстановлено обнаружение ПК и подключение TerminalV Mobile через Tailscale. Телефон выбирает компьютер, а пользователь подтверждает доступ устройства в окне TerminalV на ПК. Разрешения сохраняются; в настройках можно отозвать доступ телефонов.
- Исправлена работа шлюза с уже запущенными сессиями: окно TerminalV и мобильный клиент используют общее подключение к фоновому host. Телефон получает историю и текущий вывод, может вводить команды и менять размер терминала. Подключение другого телефона не повторяет всю историю в уже открытых терминалах.
- Список на телефоне соответствует каталогу рабочего стола: сохраняются названия, порядок, скрытые записи и активная сессия. Служебные или оставшиеся в host процессы больше не создают лишние вкладки в мобильном списке.
- Созданная с телефона сессия появляется и сохраняется на ПК без запуска второго процесса и без переключения выбранной вкладки рабочего стола.
- Сохранены исправления прокрутки и отображения терминала из 0.7.13. Обновление окна приложения сохраняет работающий фоновый host и его процессы.

## Совместимость

Исправления совместимы с **TerminalV Mobile 1.1.5**. Для устранения этой ошибки достаточно обновить Windows-приложение и нажать **«Переподключиться»** на телефоне; переустанавливать APK 1.1.5 не требуется. На ПК должны работать Tailscale и шлюз TerminalV.

## Проверка перед выпуском

Совмещённые исходники проверены на Xeon: 28 SSH/gateway checks и 26 browser checks. Итоговая сборка 0.7.14 установлена и проверена: обнаружение ПК отвечает HTTP 200, все три текущие живые сессии доступны, их история читается, прежний host сохранён. Повторное подключение непосредственно с телефона после установки пользователем пока не подтверждено.
