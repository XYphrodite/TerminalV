# TerminalV v0.5.3

## Автор и ссылка на GitHub

- Под названием и версией приложения добавлена подпись **Автор: XYphrodite** со ссылкой на [GitHub-профиль автора](https://github.com/XYphrodite).
- Ссылка открывается во внешнем браузере обычным или средним кликом, не заменяя интерфейс терминала. Кнопка версии по-прежнему проверяет обновления.
- Подпись адаптирована к светлым и тёмным темам, имеет подсказку и выделение клавиатурного фокуса. При сворачивании списка сессий скрывается вместе с названием и версией.
- Исправлена высота боковой панели: в маленьком окне подпись и нижние кнопки не уходят за пределы экрана, прокручивается список сессий.

Нативный обработчик открывает только фиксированный HTTPS-адрес автора, не принимает произвольные ссылки или команды из интерфейса. При ошибке запуска браузера показывает сообщение с адресом профиля. Сессии и их содержимое не меняются.

## Обновление

Выполните `TerminalV update` или нажмите **Обновить** в приложении. Для ручной установки доступны self-contained ZIP для Windows x64 и SHA-256.

Для изменений v0.5.3 перезагрузка Windows не требуется: после обновления достаточно перезапуска окна приложения. Если вы переходите с версии до v0.5.2 и видите предупреждение о старом фоновом процессе, сохраните работу и перезагрузите Windows для включения обновления PATH и WSL. Рабочие сессии приложение принудительно не завершает.

## Проверки и пакет

Релизный ZIP прошёл 234 проверки без пропусков: 171 Node/браузерную, 31 PTY/транспортную, 11 SQLite и 21 проверку пакета/CLI/изолированного обновления. Проверены PowerShell 5.1 и 7, cmd, обнаружение установленного Codex при старом PATH и установленная Ubuntu. Оба запускателя возвращают `0.5.3`; версия в свойствах EXE — `0.5.3`.

Браузерные app-fixtures загружали интерфейс из распакованного ZIP. Для ссылки проверены адрес, обычный и средний клик, отмена навигации, отсутствие изменений терминальных сессий, фокус, темы и узкое окно. Внешний браузер при тестах не запускался; ручная проверка WPF/WebView2 в отдельной Windows-среде не проводилась. Установленный TerminalV, рабочий host и пользовательская база не затрагивались. Обновление проверялось на временных копиях через локальный источник релиза.

Release-сборка решения успешна, без ошибок и предупреждений MSBuild. Неблокирующие сообщения: npm allow-scripts для esbuild и Vite о JS-бандле немного больше 500 kB.
