# TerminalV v0.8.22 — обновление переменных среды в текущей вкладке

- Добавлена кнопка **«Обновить окружение»** в меню управления сессией (ПКМ по вкладке или кнопка `⋯`): оболочка перезапускается прямо в текущей вкладке с актуальными переменными среды Windows (`Machine` + `User` + свежий `PATH`), без необходимости открывать новую сессию.
- При перезапуске на месте сохраняются текущая рабочая папка (`cwd`), название, группа, цветовая метка, закрепление, параметры профиля и раскладка split-панелей, а предыдущий вывод экрана переносится в историю прокрутки (`scrollback`) с разделителем `── Окружение обновлено · оболочка перезапущена ──`.
- Добавлена обратная совместимость с уже работающим фоновым процессом `TerminalV --host` предыдущей версии, чтобы обновление окружения работало сразу после обновления приложения без перезагрузки Windows.

```powershell
TerminalV update
```
