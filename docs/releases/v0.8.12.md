# TerminalV v0.8.12 — обновление расширений

- **Проверка версий**: TerminalV сравнивает версию установленных расширений с последним релизом (через 20 с после запуска и каждые 6 часов; вручную — «Проверить обновления» в Настройки → Расширения).
- **Уведомления и кнопки**: при новой версии показывается уведомление с кнопкой «Обновить»; в списке расширений — кнопки «Обновить» и «Обновить все».
- **Безопасное применение**: пакет скачивается, проверяется (SHA256, манифест) и заменяет установленный при следующем запуске, до загрузки DLL.
- **CLI**: `TerminalV update` обновляет приложение и расширения; `--extensions` — только расширения, `--no-extensions` — только приложение; `--check` показывает и обновления расширений.
- В релиз добавлен индекс `extensions.json` с версиями и хешами расширений.

```powershell
TerminalV update
```
