# TerminalV v0.7.3 — сплит дочерней даёт сиблинга

## Изменено

- Сплит дочерней сессии снова доступен: новая сессия становится дочерней того же родителя (сиблингом выбранной), а не внуком. Было `[A | B]`, делите B → стало `[[A | B] | C`: все дети на одном уровне.
- Запрет остался только там, где сплит реально углубил бы дерево (первые панели старых вложенных раскладок) — там кнопки гаснут.
