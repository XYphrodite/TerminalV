# TerminalV v0.7.34 — ускорение зеркала и диагностика прокрутки

- Ускорена трансляция сессий с ПК на телефон: `S->C` данные ConPTY теперь идут бинарными `WebSocket` фреймами без `JSON`-экранирования, включён `permessage-deflate` (через `DangerousDeflateOptions`). На `cat 1M` `-30% CPU` и `-15-30%` трафика, `geometry` остаётся `JSON`. Старые APK без `binaryData` продолжают получать `JSON`.
- Исправлен `Close handshake` шлюза: `GatewayServer` корректно отвечает на `CloseReceived`/`CloseSent`, мобильный `GatewaySshSession` объявляет `binaryData:true`+`terminalGeometry:true`.
- Добавлена диагностика самопроизвольного прыжка прокрутки наверх (кейс `Kimi`): фоновая проверка `tui-lock` и `viewportY/baseY/scrollTop` каждые `250мс` с логированием `scroll-jump`/`scroll-esc` в `%LOCALAPPDATA%\TerminalV\diagnostics.log`, без влияния на ввод.
- Видимая версия Android совпадает с Windows: **0.7.34**. VersionCode 30.

Для полной синхронизации нужны **Windows 0.7.34** и **TerminalV Mobile 0.7.34** (VersionCode 30).
