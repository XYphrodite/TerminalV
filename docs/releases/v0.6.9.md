# TerminalV v0.6.9 — ресайз окна со всех сторон

## Исправлено

- Изменение высоты/ширины окна было доступно только сверху. Причина — `WebView2` `HWND` на всю клиентскую область перехватывал `WM_NCHITTEST` и возвращал `HTCLIENT`, `WindowChrome` не видел бока/низ. Добавлен `WindowFrame` хук `WM_NCHITTEST` с `HitTest` по `GetWindowRect` + `ResizeBorder=6`/`CaptionHeight=36` (углы `HTTOPLEFT` etc., бока `HTLEFT/RIGHT/TOP/BOTTOM`, центр верха `HTCAPTION`, `maximized` без ресайза). `GetWindowRect`/`GetWindowLong` через `P/Invoke`.

## Проверки

- `dotnet build -f net10.0-windows` 0 CS, `Pty 25/25` (новый `WindowChrome hit-test` 4 точки), `tui-refresh 2/2`, `write-chunk 7/7`.
