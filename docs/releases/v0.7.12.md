# TerminalV v0.7.12 — отрисовка Grok и восстановление терминала

- Добавлена поддержка синхронизированных обновлений экрана: кадр Grok показывается после завершения его перерисовки. Обработка вывода и ввод продолжаются во время ожидания; незавершённый кадр освобождается по тайм-ауту.
- Убрано искусственное уменьшение ширины процесса на одну колонку при восстановлении или показе скрытой сессии. Сетка xterm и передаваемые процессу размеры теперь согласованы.
- Видимая панель подгоняется перед запросом сохранённого вывода. Реальный resize отправляется после запроса replay, в том числе если сетка осталась стандартной 80×24.
- Отложенная подгонка размеров выполняется после завершения паузы изменения раскладки.
- Добавлены браузерные регрессионные проверки с настоящим xterm: завершённые кадры, порядок подключения и resize, показ скрытой сессии и изменение размеров окна. Проверки включены в CI и выпуск пакетов.

Изменения предотвращают обнаруженные причины смещения строк, но не восстанавливают уже повреждённый вывод. Восстановление старого сырого потока TUI, записанного при разных размерах окна, остаётся ограничением.

## Файлы

- `TerminalV-win-x64.zip` — полный пакет с .NET runtime.
- `TerminalV-win-x64-light.zip` — облегчённый пакет, требуется .NET 10 Desktop Runtime.
- `terminalv.hello.zip` — необязательный пример расширения.
- Для каждого ZIP опубликован файл `.sha256`.

Обновление доступно через кнопку **Обновить** в TerminalV или команду `TerminalV update`.
