# TerminalV v0.6.3 — автоподъём сессий после перезагрузки

## Исправлено

- После перезагрузки Windows вкладки оставались с оверлеем «Сессия не запущена» и требовали ручной «Перезапустить», даже для обычных `pwsh` без `startupCommand`. Причина — `newTab` считал любой `shell` профильным: `hidden || (restored && shell)` → `exited`. Теперь `hidden || (restored && startupCommand)` — обычные оболочки (даже `shell=powershell` без команды) автосоздаются (`post create`), только профили с `startupCommand` и скрытые остаются `exited` (защита от дубля серверов).
- Добавлен `diag("restore", ...)` в `newTab` для хвоста `diagnostics.log` (видно `live/restored/hidden/shell/startup`).

## Проверки

- `ui/tests/session-restore.test.js` — **6/6**: новый кейс `reboot auto-create` (plain `pwsh`/`default` → `create`, `with-cmd`/`wsl-cmd` → `exited`, `hidden` → `exited`, `live` → `attach`), 5 прежних.
- Всего `ui` — **204/204 pass**, `dotnet build -c Release` — 0 ошибок.
