# TerminalV v0.5.2

## Быстрый запуск профилей и WSL

- Меню **Профили и оболочки**: сохранённый профиль запускается одним нажатием, без редактора и повторного сохранения.
- Отдельные действия для редактирования и создания профиля; защита от повторного запуска при двойном нажатии.
- Автоматическое обнаружение Windows PowerShell, PowerShell 7, cmd и установленных дистрибутивов WSL.
- Ubuntu и другие дистрибутивы открываются сразу в новой вкладке, в домашней папке Linux. Сессия и выбранный дистрибутив сохраняются.
- Навигация клавиатурой, удержание фокуса и корректная работа меню в узком окне. При недоступности WSL сохранённые профили остаются доступны.

WSL не устанавливается и не перенастраивается. Отслеживание Linux cwd, стартовые команды и редактирование WSL-профилей пока не предусмотрены. Повторное подключение к живой вкладке не запускает оболочку заново.

## Исправление PATH и обнаружения Codex

Новые сессии получают актуальное окружение Windows, а не старый `PATH` фонового процесса. Недавно установленные Codex и другие команды становятся доступны в новых вкладках. Дополнительные переменные процесса сохраняются, если их имена не заданы в текущем окружении Windows; устаревший PATH не добавляется обратно.

Окружение уже работающих сессий не меняется. Никакие команды обновления не вводятся в открытые оболочки; значения окружения не попадают в интерфейс, базу или журнал.

## Обновление

Выполните `TerminalV update` или нажмите **Обновить** в приложении. Для ручной установки доступны self-contained ZIP для Windows x64 и файл SHA-256.

**После первого обновления с прежней версии сохраните работу и перезагрузите Windows.** Старый фоновый процесс продолжает обслуживать свои вкладки и не может получить новый код на лету. В интерфейсе появится предупреждение о старом PATH; запуск WSL через несовместимый хост явно отклоняется. Простое закрытие окна не обновляет хост. После этого разового перехода для обновления окружения достаточно создать новую вкладку.

Сохранённые настройки, профили, темы и сессии совместимы. Установленный TerminalV и рабочие сессии пользователя при подготовке релиза не затрагивались.

## Проверки и пакет

На релизном ZIP прошли 232 проверки без пропусков: 169 Node/браузерных, 31 PTY/транспортная, 11 SQLite и 21 проверка пакета/CLI/изолированного обновления. Проверены PowerShell 5.1 и 7, cmd и установленная Ubuntu. Поиск установленного Codex проверен через `Get-Command` при намеренно устаревшем PATH родительского процесса, без запуска Codex-сессии. Отдельный тест сохраняет живую оболочку и её окружение во время создания другой сессии.

Браузерные app-fixtures загружали файлы непосредственно из распакованного ZIP. Обновление проверялось на временных копиях через локальный источник релиза, без рабочего host pipe и пользовательской базы. Оба запускателя возвращают версию `0.5.2`. Ручная проверка WPF/WebView2 в отдельной Windows-среде не проводилась.

Release-сборка решения завершена без ошибок и предупреждений MSBuild. В свойствах EXE указана точная версия `0.5.2`, без автоматической метки предыдущего Git-коммита. Неблокирующие сообщения: npm allow-scripts для esbuild и Vite о JS-бандле немного больше 500 kB.
