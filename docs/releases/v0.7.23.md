# TerminalV v0.7.23 — фикс видимой ручки

- `ui`/`Mobile`: ручка `Клавиши` вынесена из скрытой панели наружу (`fixed bottom:0`, `z-index:21`, `hidden=false` + `transform`), теперь всегда видна внизу и поднимается на `var(--mobile-keys-height)` при открытии.

Для полной синхронизации нужен **TerminalV Mobile 1.1.13** (VersionCode 19).
