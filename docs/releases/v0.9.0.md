# TerminalV v0.9.0 — быстрее на слабых телефонах

- **Ограниченное восстановление экрана на телефоне:** при подключении мобильный клиент просит у шлюза только хвост истории (до 300 000 символов) вместо полного буфера в 1,5 МБ. Режимы терминала (альтернативный экран, мышь, SGR), включённые в отброшенной части, сохраняются, поэтому TUI-приложения восстанавливаются корректно. Старые шлюзы и клиенты поле `maxReplayBytes` игнорируют.
- **Плавнее поток вывода:** шлюз склеивает мелкие чанки вывода в кадры примерно по 12 мс (до 64 КБ) вместо отдельного WebSocket-фрейма на каждый. Порядок сохраняется, перед сообщением о завершении сессии буфер сбрасывается.
- **Меньше памяти и CPU на телефоне:** scrollback 2000 строк вместо 8000, сохраняемый снимок экрана ограничен 1000 строками, цикл чтения шлюза работает в пуле потоков, а не в выделенном потоке на каждую сессию.
- **Go tsnet:** мягкий лимит памяти 96 МБ и `GOGC=50` для встроенного Tailscale.
- **AI Limits 1.4.3:** состояние `agy` больше не показывается как «авторизация истекла» при сетевых и прочих временных ошибках; ошибка авторизации определяется по выводу `agy`, повторные запросы идут с нарастающей паузой.

```powershell
TerminalV update
```
