# TerminalV v0.7.18 — цифры на телефоне, клавиатура и подгонка размера

- Телефон: верхнее пустое пространство убрано — `mobile-keys` теперь `column + width:100%` с `requestAnimationFrame(resize)` при `mobile ↔ desktop`, `panes` сразу подгоняется под новую высоту.
- Телефон: в нижнюю панель добавлены цифры `0..9` (две строки `digits`/`nav`, `flex-wrap:nowrap + overflow-x:auto`, `min-width 32px` для цифр), скролл по горизонтали, высота ~99px вместо 191px.
- Телефон: нажатие на кнопку панели больше не открывает клавиатуру — убран `tab.term.focus()`, остался только `preventDefault` на `pointerdown` + флаг `pointerHandled` для `click`.
- Телефон: по умолчанию большой десктоп скроллится пальцем; новый `MobileFitMode` (`AppSettings.MobileFitMode`, `data-mobile-only` чекбокс «Подстраивать размер сессии под телефон» в `Настройки → Мобильный размер`) — когда включён, `TryAttach`/`HandleResize` шлют `ResizeAsync(cols,rows)` на шлюз, PTY десктопа подстраивается под вьюпорт телефона без прокрутки (переключение без пересоздания).

Для полной синхронизации нужен **TerminalV Mobile 1.1.8** (VersionCode 14).
