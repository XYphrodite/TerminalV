# TerminalV v0.7.46 — вставка изображений в чат

- **Картинка из буфера обмена вставляется в терминал как путь к временному PNG**: скопируйте снимок экрана и нажмите `Ctrl+V` (или правый клик) — вместо картинки в строку вставится путь вида `C:\Users\...\Temp\TerminalV\pastes\paste-….png`. Текст из буфера всегда вставляется как раньше; путь появляется, только если буфер содержит одно изображение.
- **В `hermes --tui` картинка прикрепляется к сообщению автоматически**: путь в начале ввода hermes распознаёт как вложение (как при перетаскивании файла) и показывает «📎 Auto-attached image». Вставьте путь, при желании допишите после него вопрос и нажмите `Enter`. Windows-пути hermes понимает и из WSL (конвертирует в `/mnt/c/…`), путь с пробелами вставляется в кавычках.
- Временные файлы складываются в `%TEMP%\TerminalV\pastes` и удаляются при выходе из приложения.
- На телефоне и в «Зеркале» вставка изображений не работает: сессия выполняется на другой машине, где путь к файлу на устройстве ничего не значит.
- Тесты: 3 новых проверки логики вставки (пути с пробелами, приоритет текста, пустой буфер). Весь прогон — 372/372.
- Видимая версия Android совпадает с Windows: **0.7.46**. VersionCode 42.

Для полной синхронизации нужны **Windows 0.7.46** и **TerminalV Mobile 0.7.46** (VersionCode 42).
