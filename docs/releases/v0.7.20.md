# TerminalV v0.7.20 — локализация + авто-язык

- Локализация через `Microsoft.Extensions.Localization` + `.resx` (`Localization/Resources/Strings.resx` / `Strings.en.resx` / `Strings.ru.resx`) и `IStringLocalizer` для WPF/MAUI (`LocalizationService`, `TranslateExtension {loc:Translate}`).
- Web UI `ui/src/i18n.js` + `ui/src/locales/ru.json` / `en.json` (68 ключей), `<select id="language">` в настройках.
- Первый запуск теперь берёт язык из системы (`CultureInfo.CurrentUICulture`: `en` → `en`, иначе `ru`), дальше сохраняется в `%LOCALAPPDATA%\TerminalV\terminalv.db` и переживает переустановку (`Programs\TerminalV` отдельно).
- Фикс потери сессий при обновлении: `AppDatabase.SaveSessions` не стирает БД пустым списком поверх заполненной (гонка `terminalvFlush` до `init`).
- Кроссплатформенный `DesktopInstanceLease.TryAcquire` (WAL/lock на Linux).

Для полной синхронизации нужен **TerminalV Mobile 1.1.10** (VersionCode 16).
