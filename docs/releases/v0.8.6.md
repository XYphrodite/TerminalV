# TerminalV v0.8.6 — JSON null hardening

Патч: `add-extension` и загрузка расширений больше не падают с `The requested operation requires an element of type 'Number', but the target element has type 'Null'.` (в 0.8.5 релиз не собрался из-за рекурсии в converter).

- Манифест расширения парсится вручную через `JsonDocument`.
- `NullToDefaultConverter` для `int`/`long`/`double`/`bool`: JSON `null` → значение по умолчанию, без рекурсии при записи.
- `IncomingMessage.Cols/Rows` — `int?`; resize/create устойчивы к `cols: null`.
- Код выхода процесса читается только если это число.
- `add-extension` печатает полный stack trace.

```powershell
TerminalV update
TerminalV add-extension https://github.com/XYphrodite/TerminalV/releases/download/v0.8.6/terminalv.ai-limits.zip --replace
```
