# TerminalV v0.7.5 — сохранение tail-токена и фикс ресайза

## Исправлено

- **Mobile: сохранение параметров** — `tail auth token` (Tailscale Auth Key) теперь сохраняется вместе с остальными параметрами подключения (`host`, `port`, `username`, `gatewayToken` и т.д.) через `Preferences` и восстанавливается при следующем запуске.
- **SSH ресайз** — `Resize to 63x20 requested but window-change not supported` больше не показывает красный баннер. `TrySendWindowChange` теперь пробует все известные сигнатуры `SendWindowChangeRequest` и тихо сохраняет новый размер для переподключения, вместо `RaiseError`.

## Новое (из v0.7.4)

- Сплит-кнопка «Новая вкладка» (перенесено из неудачного v0.7.4): основная часть — вкладка по умолчанию, стрелка — выбор профиля из всех доступных.

## Проверки

- `ui/tests/new-tab-split.test.js`: 4/4; `gateway-settings` и остальные UI-тесты — зелёные; `node --check` чистый.
- Windows-сборка — через GitHub Actions при публикации тега.
