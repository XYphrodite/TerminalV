# TerminalV v0.8.30 — Canvas-рендерер на ПК при выключенном WebGL

- **Ровные таблицы и спарклайны при отключённом аппаратном рендеринге:** раньше при выключении опции «Аппаратный рендеринг (WebGL)» на ПК `ensureCanvas` блокировался проверкой мобильного UI и терминал откатывался в базовый DOM-рендерер. Из-за этого псевдографика (`─`, `│`, `╭`, `╯`) рисовалась шрифтовыми глифами с разрывами по высоте строки, а строки со спарклайнами (`█`) или fallback-символами сдвигались по горизонтали. Теперь на ПК при выключенном WebGL (а также при потере WebGL-контекста) включается `CanvasAddon` со встроенным `customGlyphs` — рамки таблиц остаются сплошными, а колонки идеально выровнены.
- **Очистка текстурного атласа Canvas:** при ресайзе alternate-буфера TUI сбрасывается и атлас `CanvasAddon`, а при закрытии/скрытии вкладок аддон корректно освобождается.

```powershell
TerminalV update
```
