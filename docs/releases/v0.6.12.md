# TerminalV v0.6.12 — диагностика ресайза ConPTY

## Изменено

- `ConPtySession.Resize` больше не глотает молча код возврата `ResizePseudoConsole`: при `HRESULT != 0` в `diagnostics.log` пишется `pty: Resize failed id=... cols=... rows=... hr=0x...`.
- Нужно для локализации бага «в узком окне пропадает правая часть»: клиентский фит по логам отрабатывает (сетка сужается, заказы `resize` уходят), а применяет ли их ConPTY — было не видно. Повтори сужение и смотри хвост лога: строки `Resize failed` с `hr` докажут отказ ConPTY, их отсутствие — оправдает PTY и вернёт расследование в рендер.

- Windows-сборка и прогон в этой среде не запускались (`dotnet` недоступен) — сборка идёт через GitHub Actions при публикации тега.
