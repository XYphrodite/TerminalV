# TerminalV v0.7.15 — восстановление прокрутки Grok

- Внешняя полоса прокрутки скрывается, когда приложение само обрабатывает колесо, включая `grok --no-alt-screen`. В `grok --minimal` и обычной оболочке доступна история терминала. Переключение не удаляет историю и не меняет размер терминала.
- Фоновый host сохраняет режимы экрана и мыши при сокращении истории вывода. При повторном открытии длительной сессии Grok команды включения его экрана и прокрутки больше не теряются вместе с началом лога.
- Сохранённые снимки экрана сохраняют формат SGR для событий мыши вместе с режимом её обработки.
- Включены изменения подключения TerminalV Mobile через Tailscale из установленной сборки 0.7.14: обнаружение ПК, подтверждение доступа телефона, общий канал к фоновому host и каталог сессий рабочего стола. Совместимо с TerminalV Mobile 1.1.5.

## Уже открытые сессии

Обновление сохраняет работающий фоновый host и процессы. Если старый host уже потерял начальные команды Grok, новое окно не может восстановить их из усечённого вывода. В самом Grok выполните `/minimal`, затем `/fullscreen`: эти команды заново включают экран и мышь внутри той же беседы. Перезапуск Grok не требуется.

Новый алгоритм хранения истории работает в host, запущенном из новой версии. Уже работающий старый host продолжает использовать прежний алгоритм до своего завершения; обновление не останавливает его принудительно.

## Проверка

Режимы `grok`, `--fullscreen`, `--no-alt-screen`, `--minimal` и переключение `/minimal` → `/fullscreen` проверены через отдельную ConPTY установленного Grok 1.0.41, без пользовательской истории. Перемещение длинной пользовательской беседы этим экспериментом не проверялось.

Проверки браузера охватывают передачу колеса, видимость полосы, сохранность истории, переключение режимов и восстановление SGR. Проверки host охватывают усечение истории и управляющие последовательности на границах порций вывода. Сборка и проверки Windows выполняются в GitHub Actions.
