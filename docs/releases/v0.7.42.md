# TerminalV v0.7.42 — мобильный рендер и жесты

- **Нативный вертикальный скролл** на телефоне (`touch-action: pan-y` вместо `none`): доверенные жесты уходят в браузер с инерцией и fling, горизонтальная панорама широкой сетки остаётся на JS. Синтетические события (тесты) используют прежний ручной путь с gain ×1.35.
- **Кэш layout зеркала** (`measureCache` + rAF-коалесинг `onRender`): `getComputedStyle` и метрики ячейки считаются один раз на размер шрифта, а не на каждый кадр отрисовки TUI.
- **WebGL-гейт для телефона** (`webglAllowed`): аппаратный рендер включается только для phone-sized сетки (MobileFitMode / прямой SSH). Зеркало размера рабочего стола рисуется DOM-рендером — большая текстура тормозила WebView. Подсказки в настройках.
- Хинты H1 продублированы в мобильный `wwwroot/index.html` (отдельный от desktop HTML).
- Тесты: `mirror-viewport` (3), `hardware-rendering` (4), браузерные mirror/mobile. Весь `selection.test.js` + unit — 359/359.
- Видимая версия Android совпадает с Windows: **0.7.42**. VersionCode 38.

Для полной синхронизации нужны **Windows 0.7.42** и **TerminalV Mobile 0.7.42** (VersionCode 38).
