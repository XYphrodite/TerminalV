# TerminalV v0.8.19 — исправление доступа к SessionHost и обновление AI Limits

- Исправлена ошибка `Access to the path is denied.` при открытии сессий обычным пользователем, если фоновый процесс `TerminalV --host` был ранее запущен от имени Администратора: мьютекс и именованный канал теперь явно выдают права текущему пользователю Windows (`SID`), а при недоступности фонового хоста терминал автоматически переключается на локальный запуск `ConPtySession`.
- Расширение **AI Limits (`1.3.6`)**: скрытие устаревших/истёкших лимитов, проверка срока действия JWT для **Codex**, поддержка авторизации и месячной квоты Token Plan для **MiMo** (`platform.xiaomimimo.com`), а также проверка авторизации **Muse** внутри WSL (`~/.config/muse/auth.json`).

```powershell
TerminalV update
```
