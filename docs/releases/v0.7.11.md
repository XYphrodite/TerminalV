# TerminalV v0.7.11 — расширения C# + JavaScript

- Добавлен механизм расширений Desktop API v1: пакет с `extension.json`, C# DLL для фоновой логики и JavaScript-модулем для интерфейса. Поддерживаются также пакеты только с C# или только с JS.
- Расширения могут добавлять панели сайдбара и настроек, команды и уведомления; обмениваться запросами и событиями между C# и JS. Общие данные сохраняются в SQLite, секреты — с шифрованием DPAPI CurrentUser.
- В настройках появился раздел **Расширения** со списком пакетов, ошибками загрузки и кнопкой открытия папки. Новые расширения выключены по умолчанию; включение и отключение применяются после перезапуска.
- Добавлены SDK `TerminalV.Extensibility`, руководство для разработчиков и пример `terminalv.hello` с панелью, сохраняемым счётчиком и фоновыми событиями. Пример поставляется отдельным архивом и не устанавливается автоматически.
- В установщике сохранён работающий фоновый host: замена пакета не завершает его сессии, предыдущие файлы сохраняются в резервной папке, при ошибке проверки новой копии выполняется откат.

## Как установить расширение

Откройте **Настройки → Расширения → Открыть папку расширений**. Распакуйте пакет так, чтобы манифест находился по пути `%LOCALAPPDATA%\TerminalV\extensions\publisher.name\extension.json`. Перезапустите TerminalV, включите пакет в настройках и перезапустите приложение ещё раз.

Для примера из релиза итоговый путь — `%LOCALAPPDATA%\TerminalV\extensions\terminalv.hello\extension.json`. Для обновления или удаления пакета сначала закройте TerminalV.

Расширения выполняются с правами приложения; это не песочница. Устанавливайте доверенные пакеты. Расширения VS Code и мобильный клиент этим API не поддерживаются. Данные расширений хранятся в `%LOCALAPPDATA%\TerminalV\extension-data\`, отдельно от устанавливаемого пакета приложения.

## Файлы

- `TerminalV-win-x64.zip` — полный пакет с .NET runtime.
- `TerminalV-win-x64-light.zip` — облегчённый пакет, требуется .NET 10 Desktop Runtime.
- `terminalv.hello.zip` — необязательный пример расширения.
- Для каждого ZIP опубликован файл `.sha256`.

Перед публикацией workflow проверяет оба пакета, восстановление сессий, загрузку DLL, DPAPI, запросы и события расширений, JS API и интерфейс расширений из full/light-пакетов.
