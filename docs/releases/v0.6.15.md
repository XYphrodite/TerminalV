# TerminalV v0.6.15 — вставка больших текстов файлом

## Новое

- Вставка длиннее 4000 символов больше не идёт текстом через PTY: хост сохраняет буфер в `%TEMP%\TerminalV\pastes\paste-<guid>.txt`, а в терминал вставляется путь к файлу. Повод — TUI-клиенты вроде `muse`, которые переваривают bracketed paste кусками по 2000 символов (~10 секунд на 27КБ); путь вставляется мгновенно.
- Короткие вставки — как раньше, без изменений. Ошибка сохранения или таймаут (5 с) — молча вставляется исходный текст, вставка никогда не ломается.
- Временные файлы живут до закрытия окна (`Closed` чистит папку целиком).

## Проверки

- `ui/tests/paste-file.test.js`: 4/4 pass (границы порога, 27КБ/157КБ, не-строки); `write-chunk.test.js` без падений; `node --check` обоих JS-файлов чистый.
- Полный UI-сьют: 43 pass, 14 fail — все требуют Chromium (`TERMINALV_TEST_BROWSER`), в Linux-контейнере невыполнимы, с фичей не связаны.
- Windows-сборка — через GitHub Actions при публикации тега. C# (мост + `PasteFileStore`) локально не компилировался — проект Windows-only.
