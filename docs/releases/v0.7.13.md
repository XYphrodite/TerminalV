# TerminalV v0.7.13 — прокрутка Grok

- Исправлено удаление истории терминала при включении приложением mouse reporting или переходе на альтернативный экран. История обычного буфера теперь сохраняется при переключениях Grok между полноэкранным интерфейсом и режимом с обычной прокруткой.
- Убрана зависающая блокировка прокрутки после выключения мышиного режима, сброса терминала и составных или фрагментированных управляющих последовательностей. Режим определяется по фактическому буферу xterm.
- Колесо использует стандартную обработку xterm: прокручивает обычную историю, передаёт mouse reports приложению или клавиши вверх/вниз полноэкранному приложению без mouse reporting.
- Ctrl/Meta+колесо изменяет масштаб TerminalV без отправки ввода в приложение.
- Добавлены браузерные проверки настоящих событий колеса, сохранности истории, переключения режимов и масштабирования.

Обновите приложение через **Обновить** или `TerminalV update`. История, уже удалённая предыдущей версией, не восстанавливается этим исправлением.

## Файлы

- `TerminalV-win-x64.zip` — полный пакет с .NET runtime.
- `TerminalV-win-x64-light.zip` — облегчённый пакет, требуется .NET 10 Desktop Runtime.
- `terminalv.hello.zip` — необязательный пример расширения.
- Для каждого ZIP опубликован файл `.sha256`.
