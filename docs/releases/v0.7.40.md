# TerminalV v0.7.40 — быстрая прокрутка зеркала на телефоне

- Прокрутка истории сессии на телефоне больше не «медленная»: это был кастомный pan 1:1 без инерции, а не слабый телефон. В `ui/src/mirror-viewport.js` ход вертикального жеста ×1.35 (`MIRROR_SCROLL_GAIN`, в v0.7.22 был ×1.2 и потом потерялся) и **fling** после отрыва пальца (затухание ~90ms, несколько экранов). Горизонтальная панорама широкой сетки ПК без изменений.
- Тесты: `ui/tests/mirror-viewport.test.js` (2) и browser mirror/mobile. Весь `selection.test.js` + unit — 244/244.
- Видимая версия Android совпадает с Windows: **0.7.40**. VersionCode 36.

Для полной синхронизации нужны **Windows 0.7.40** и **TerminalV Mobile 0.7.40** (VersionCode 36).
