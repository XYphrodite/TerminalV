# TerminalV v0.8.7 — JSON null hardening (релиз)

Стабильный релиз после серии патчей: `add-extension` и загрузка расширений не падают с `The requested operation requires an element of type 'Number', but the target element has type 'Null'.`

- Манифест расширения парсится вручную через `JsonDocument`.
- `NullToDefaultConverter` для `int`/`long`/`double`/`bool`: JSON `null` → default, без рекурсии при записи.
- `IncomingMessage.Cols/Rows` — `int?`; resize/create устойчивы к `cols: null`.
- Код выхода процесса читается только если это число.
- `add-extension` печатает полный stack trace.
- Mobile/Mirror собираются с общим `JsonNullToDefault`.

```powershell
TerminalV update
TerminalV add-extension https://github.com/XYphrodite/TerminalV/releases/download/v0.8.7/terminalv.ai-limits.zip --replace
```
