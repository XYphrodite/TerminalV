# TerminalV v0.8.0 — стабильный мобильный терминал

Итоговая точка мобильной линии 0.7.x: телефон и десктоп работают как одно рабочее место.

- **Телефон задаёт размер PTY, десктоп не перебивает.** Пока мобильный клиент подключён, сетка строится по экрану телефона (например 47×44), а не по окну Windows. Клавиатура и повороты пересчитывают размер без разрывов. Сетка desktop attachment больше не откатывает resize назад.
- **Убран дедлок resize.** Событие `GeometryChanged` больше не вызывает перекрёстную блокировку при одновременном изменении геометрии с телефона и с десктопа.
- **Мобильный harness и TUI.** Grok / Codex / Muse и другие CLI-агенты корректно определяются как TUI (`tui-lock`, `app-wheel`), ввод с телефона доходит до агента, ответ виден на телефоне.
- Сохранены проверенные ограничения прошлых релизов: нет горизонтального скролла, вертикальная прокрутка истории работает, canvas-рендер на телефоне.

Видимая версия Android совпадает с Windows: **0.8.0**. VersionCode 52.

Для полной синхронизации нужны **Windows 0.8.0** и **TerminalV Mobile 0.8.0** (VersionCode 52).
