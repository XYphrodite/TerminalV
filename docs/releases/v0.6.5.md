# TerminalV v0.6.5 — вставка без «по строчке»

## Исправлено

- Вставка в `muse` шла «сначала одна, потом вторая» — по строчке с паузой. Причина: `Diagnostics/Diag` делал синхронный `File.AppendAllText` под `lock` на каждый чанк `4000`/`8192` (paste → `SessionClient` → `ConPty`). На 50К это 13 чанков × 30-50ms = 400-600ms построчной печати. Теперь `Diag.Log` не блокирует горячий путь: `Debug.WriteLine` сразу, файл — асинхронный батч `ConcurrentQueue` + `FlushQueue` 50 строк, `Interlocked` защита, ротация 5MB.

## Проверки

- `dotnet build -c Release -f net10.0-windows` — 0 `error CS`, `Pty large paste 100K <500ms` и `concurrent 4K` <2000ms — **25/25 pass**.
