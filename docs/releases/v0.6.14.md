# TerminalV v0.6.14 — меньший минимальный размер окна

## Изменено

- Минимальный размер окна опущен с 800×480 до 560×360 (`MinWidth`/`MinHeight` в `MainWindow.xaml`). Хук `WM_GETMINMAXINFO` из v0.6.13 подхватывает цифры сам, код менять не понадобилось.
- 560 — брейкпоинт, на котором сайдбар уже переходит в компактные 180px; терминалу остаётся ~38×14 клеток, вёрстка цела.

## Проверки

- Windows-сборка и прогон в этой среде не запускались (`dotnet` недоступен) — сборка идёт через GitHub Actions при публикации тега. Приёмка: окно упирается в 560×360 и дальше не идёт.
