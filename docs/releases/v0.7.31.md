# TerminalV v0.7.31 — телефон подключается без подтверждения

- Окно «Разрешить этому устройству» на ПК больше не показывается. Телефон из той же сети Tailscale получает доступ сразу, устройство запоминается.
- Отзыв доступа на компьютере по-прежнему отключает уже открытый канал.
- В списке компьютеров на телефоне всегда «Открыть сессии».
- Видимая версия Android совпадает с Windows: **0.7.31**. VersionCode 27.

Для полной синхронизации нужен **TerminalV Mobile 0.7.31** (VersionCode 27). Обновление нужно и на ПК: диалог показывал Windows-приложение.
