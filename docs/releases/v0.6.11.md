# TerminalV v0.6.11 — ресайз окна: WebView2 больше не перекрывает края

## Исправлено

- Растягивание окна за левый/правый/нижний край не работало: `WebView2` — дочерний `HWND` на всю область контента, он съедал `WM_NCHITTEST` там, где касался края окна (airspace), и хук `WindowFrame` в родителе бока/низ не видел. Верх тянулся (там WPF-капшен), кнопки капшена уже чинились исключением `CaptionButtonsWidth=138`.
- Теперь веб-контент вставлен внутрь на `ResizeBorder=6` (`ContentRoot` `Margin="6,0,6,6"` слева/справа/снизу, сверху `0` — там капшен), открывая полосу WPF для хит-теста ресайза. При `maximized` отступ схлопывается в `0` (`UpdateMaximizeGlyph`), где ресайз выключен.

## Проверки

- `Pty` новый durable-тест `WindowChrome WebView inset leaves WPF resize border (airspace fix)` — `ContentRoot`/`Margin` в XAML и синхронизация марджина в code-behind.
- Windows-сборка и полный прогон в этой среде не запускались (`dotnet` недоступен) — проверить `dotnet build -f net10.0-windows` и `Pty` на Windows перед публикацией ZIP.
