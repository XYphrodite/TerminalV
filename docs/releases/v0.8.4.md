# TerminalV v0.8.4 — фикс add-extension (JSON null)

Патч к v0.8.3: установка расширения падала с ошибкой `The requested operation requires an element of type 'Number', but the target element has type 'Null'.`

- **`apiVersion` в манифесте теперь `int?`** — JSON `null` или отсутствующее значение больше не роняют `System.Text.Json`, а дают понятное «Unsupported extension API version».
- **AI Limits** не падает целиком, если один провайдер встретил `null` в JSON (`utilization`, `used_dollars` и т.п.): поля читают только как числа, ошибки изолированы по каждому сервису.
- `add-extension` безопаснее читает `id` из манифеста.

```powershell
TerminalV add-extension https://github.com/XYphrodite/TerminalV/releases/download/v0.8.4/terminalv.ai-limits.zip
```
