# TerminalV v0.5.0

## Новое

- Поиск по выводу: `Ctrl+Shift+F`, кириллица, подсветка, счётчик и переход между совпадениями.
- Подтверждение завершения работающей сессии для крестика, средней кнопки мыши и `Ctrl+Shift+W`.
- Новая вкладка наследует текущую папку PowerShell; поддержаны Windows PowerShell 5.1 и PowerShell 7.
- Группы проектов, цветовые метки, закрепление, поиск вкладок и скрытие с сохранением работающего процесса.
- Уведомления BEL: подсветка, отключение звука для сессии и ограничение частоты. Восстановленная история не подаёт повторных сигналов.
- Профили запуска: оболочка, папка, название, цвет и необязательная команда. Подключение к живой сессии не повторяет стартовую команду.
- Разделение справа/снизу: до восьми панелей, изменение размеров, `Alt+стрелки` для фокуса и сохранение расположения. Отделение панели не завершает процесс.

## Исправления обновления

- Неполный ZIP отклоняется до замены EXE.
- Консольный `TerminalV.com` обновляется вместе с интерфейсом; блокировка файла сохраняет возможность повторной попытки.
- Ошибки запуска или записи служебного маркера откатывают замену EXE.
- Служебные пути проверяются перед перемещением/очисткой. Повторная установка поверх ожидающего обновления запрещена.
- Упаковка больше не удаляет прежние файлы в `artifacts`.

## Важно при обновлении

Обновление: `TerminalV update` или кнопка «Обновить». Для ручной установки доступны ZIP и файл SHA-256.

Старый фоновый процесс может продолжать обслуживать рабочие сессии. Если приложение сообщает о несовместимом хосте, сохраните работу и перезагрузите Windows для включения профилей и интеграции текущей папки. Простое закрытие окна сохраняет фоновый процесс.

Автоматическое определение завершения команды и ожидания ответа Muse пока не реализовано. Ручная проверка WPF/WebView2 и обновления с открытыми окнами в отдельной Windows-среде не проводилась; рабочие сессии пользователя не затрагивались.

## Проверки и пакет

На релизном ZIP прошли все 197 автоматических проверок: 148 Node/браузерных, 18 PowerShell 5.1/7, cmd и ConPTY, 10 SQLite и 21 проверка пакета/CLI/изолированного обновления. Пропусков нет. Release-сборка решения завершена без ошибок и предупреждений MSBuild; npm выводит неблокирующее предупреждение allow-scripts для esbuild.

Браузерные app-fixtures загружали интерфейс из распакованного ZIP. Обновление проверялось на временных копиях через локальный источник релиза, без GitHub, рабочего host pipe и пользовательской базы. Обе команды `TerminalV.exe --version` и `TerminalV.com --version` вернули `0.5.0`.
