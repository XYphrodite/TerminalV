# TerminalV v0.8.17 — индикаторы статусов в AI Limits 1.3.2

- В расширении `terminalv.ai-limits` (`1.3.2`) точки статуса разделены по форме и цвету:
  - Залитые (`●`) — авторизация активна (`#3ecf8e` `<60%`, `#e2b93b` `60–84%` / устаревший кэш, `#e26d3b` `85–99%`, `#e25555` `100%`).
  - Выколотые (`○`) — жёлтое кольцо при истёкшей авторизации, серое кольцо при отсутствии входа, тусклое пунктирное кольцо если CLI не установлен.

```powershell
TerminalV update
```
