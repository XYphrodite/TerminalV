# TerminalV v0.7.19 — APK прямо в релизе

- Релизный пайплайн `.github/workflows/release.yml` теперь собирает Android APK inline: `setup-java 17` + `setup-go` + `dotnet workload install maui` → `Build tsnet AAR` → `npm build + copy-mobile-ui.js` → `dotnet publish -f net10.0-android` → `TerminalV-Mobile.apk` + `.sha256` публикуются вместе с `win-x64.zip` одним `gh release create`.
- `mobile-apk.yml` оставлен для CI на `main/PR` (артефакт без релиза).

Для полной синхронизации нужен **TerminalV Mobile 1.1.9** (VersionCode 15).
