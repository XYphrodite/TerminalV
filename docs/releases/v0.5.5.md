# TerminalV v0.5.5

## Ярлыки приложения

- Меню «Пуск»: пользовательский ярлык создаётся по умолчанию при установке.
- Рабочий стол: опциональный ярлык, параметр установщика `-DesktopShortcut`. `-NoShortcut` отключает создание обоих ярлыков, не удаляя существующие.
- В приложении: **Настройки → Ярлыки приложения → Создать ярлыки**. Выберите «Меню „Пуск“» и/или «Рабочий стол». Работает и для распакованной ZIP-версии.
- Ярлыки ведут к текущему `TerminalV.exe` и используют его иконку. Учитываются перенесённые системные папки, в том числе рабочий стол OneDrive; права администратора не нужны.
- Повторное создание обновляет иконку без дубликатов и сохраняет пользовательские настройки ярлыка. Ссылки на другие копии или с дополнительными аргументами не перезаписываются: приложение показывает причину отдельно для каждого расположения.
- Создание выполняется в фоне. Повторные нажатия не дублируют операцию, ошибки допускают явную повторную попытку. Windows получает адресное уведомление об изменении ярлыка, без перезапуска Explorer и автоматического закрепления на панели задач.

Панель «Оформление» переименована в «Настройки». Ввод, вывод, копирование, вставка и протокол фонового host не менялись.

## Обновление

Выполните `TerminalV update` или нажмите **Обновить** в приложении. Для ручной установки доступны self-contained ZIP для Windows x64 и файл SHA-256.

После обновления откройте **Настройки → Ярлыки приложения**. Автообновление само по себе не создаёт ярлыки и не восстанавливает удалённые. Для новой функции не нужен перезапуск фонового host.

Если перемещаете ZIP-папку, уберите или переименуйте старые ярлыки и создайте новые из перемещённого приложения. Обновление ярлыков не гарантирует сброс старого значка закреплённой кнопки панели задач: кэш Explorer отдельно не очищается.

## Проверки и пакет

Релизный ZIP прошёл 260 проверок без пропусков: 180 Node/браузерных, 31 PTY/транспортную, 11 SQLite, 21 пакета/CLI/изолированного обновления, 9 Windows-ярлыков и 8 сценариев ярлыков установщика. Проверены PowerShell 5.1 и 7, cmd, поиск установленного Codex при старом PATH без запуска CLI и установленная Ubuntu. Оба запускателя возвращают `0.5.5`; ProductVersion EXE и версия в упакованном интерфейсе — `0.5.5`.

Браузерные app-fixtures загружали интерфейс из распакованного ZIP. Реальные `.lnk` проверялись в отдельных временных папках, с подменой системных расположений и уведомлений Shell. Пользовательские ярлыки, установленное приложение, рабочий host и база не изменялись. Ручная проверка WPF/WebView2-окна и значка панели задач в отдельной Windows-среде не проводилась.

Release-сборка решения успешна, без ошибок и предупреждений MSBuild. Сохранились неблокирующие сообщения npm allow-scripts для esbuild и Vite о JS-бандле чуть больше 500 kB.
