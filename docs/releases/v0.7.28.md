# TerminalV v0.7.28 — мобильный терминал: скорость и весь экран

- Вертикальный жест в зеркале сессии снова крутит историю xterm (`.xterm-viewport`), а не короткую высоту окна. Горизонтальный жест по-прежнему сдвигает широкую сетку.
- На телефоне выключен WebGL: аппаратный рендерер перерисовывал всю сетку компьютера и тормозил ввод. Обычная отрисовка показывает только видимые строки.
- Убрана пустая полоса сверху: панель разделения скрыта, пока панель одна, поля вокруг терминала сняты, у панели «Сессии» нет лишнего верхнего отступа.
- Текст доходит до ручки «Клавиши». Если сетка компьютера короче окна, она растягивается по высоте, и нижняя строка не висит в пустоте.

Для полной синхронизации нужен **TerminalV Mobile 1.1.18** (VersionCode 24).
