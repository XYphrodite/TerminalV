# TerminalV v0.9.1 — надёжное восстановление многих живых сессий

- **Исправлен сбой подключения при большом числе живых вкладок:** при открытии окна desktop-клиент больше не запускает одновременно по отдельному потоку `Task.Run` на каждую вкладку (что при числе вкладок ≥ числа потоков CPU приводило к голоданию .NET ThreadPool, зависанию чтения пайпа и массовому `The operation has timed out.`). Подключение к фоновому хосту теперь идёт последовательно в одном воркере, а таймер ожидания (30 с) стартует отдельно для каждой сессии в момент её очереди.
- **Совместимость с уже запущенным фоновым процессом:** `SessionClient.Attach` отправляет `attach` и барьерный `list` одной записью в пайп, буферы чтения/записи увеличены с 4 КБ до 64 КБ, а для новых запусков хоста увеличены и буферы самого `NamedPipeServerStream` (64 КБ). Также убран лишний повторный `SendInit()` при старте окна.
- **Приоритет активной вкладки:** при восстановлении сессий первыми подключаются активная и видимые панели, а фоновые вкладки подтягиваются следом.
- **Безопасное восстановление при таймауте:** если подключение к живой сессии всё же не успело завершиться вовремя, вместо деструктивной кнопки «Перезапустить» (которая убивала живую оболочку) показывается кнопка **«Повторить подключение»**, безопасно переподключающаяся к уже идущему дампу без дублирования вывода и без остановки процесса.

```powershell
TerminalV update
```
