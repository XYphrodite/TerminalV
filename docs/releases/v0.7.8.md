# TerminalV v0.7.8 — сохранение сессий

- Закрытие окна дожидается записи сессий в SQLite. Если сохранить данные не удалось, окно остаётся открытым и показывает ошибку.
- Быстрое закрытие при запуске и восстановление вывода больше не перезаписывают сохранённые сессии пустым состоянием. Учитывается ещё не обработанный вывод терминалов, включая скрытые вкладки.
- Непрерывный поток вывода больше не откладывает автосохранение бесконечно: добавлен максимальный интервал ожидания в две секунды.
- Самообновление использует тот же порядок сохранения. Обновление из командной строки больше не убивает старое окно принудительно и запускает новое после его завершения.
- Исправлена потеря кириллицы в рабочей папке PowerShell при кодировках вроде CP437. Пользовательская кодировка не меняется.

Для защиты общего списка сессий одновременно открывается одно окно TerminalV. Повторный запуск сообщает об уже открытом окне; дополнительные терминалы доступны во вкладках и панелях. Перед первым запуском этой версии закройте окна прежних версий.

Фоновый процесс прежней версии продолжает обслуживать работающие сессии после обновления окна. Чтобы применить исправление кириллических путей к новым сессиям, завершите нужные задачи и перезагрузите Windows. Сами запущенные программы перезагрузку не переживают; сохраняются вкладки и снимок вывода.

Проверки Windows CI: сборка приложения, 16 проверок SQLite и блокировки второго окна, 31 проверка ConPTY/фонового процесса, 18 тестов сохранения и 55 браузерных проверок. Кириллические пути проверены под CP437 в Windows PowerShell и PowerShell 7. Перед публикацией также проверяются восстановление прокрутки и оба ZIP-архива: состав, CLI, установка обновления и откат. Браузерные проверки сессий используют интерфейс из собранного архива.

Архив `TerminalV-win-x64.zip` содержит .NET runtime; `TerminalV-win-x64-light.zip` требует установленный .NET 10 Desktop Runtime. Для обоих архивов опубликованы файлы SHA-256.
