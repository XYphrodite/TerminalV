# TerminalV v0.7.9 — восстановление состояния окна

- TerminalV запоминает, было ли окно развёрнуто, и восстанавливает этот режим до первого показа при повторном запуске, в том числе после обновления.
- Сворачивание на панель задач не сбрасывает развёрнутость: если закрыть свёрнутое окно, оно откроется в последнем обычном или развёрнутом режиме.
- Режим сохраняется при изменении и при закрытии, независимо от загрузки интерфейса и сохранения его настроек.

Сохранение режима начинается с этой версии. После первого запуска выберите нужное состояние окна; последующие запуски будут его восстанавливать.

Windows CI проверяет шесть сценариев с настоящими WPF-окнами, включая раннее закрытие, сворачивание и ошибки хранения, а также сохранение режима в SQLite. Перед публикацией проходят проверки обоих ZIP-архивов, сессий, ConPTY и интерфейса.

Архив `TerminalV-win-x64.zip` содержит .NET runtime; `TerminalV-win-x64-light.zip` требует установленный .NET 10 Desktop Runtime. Для обоих архивов опубликованы файлы SHA-256.
