# TerminalV v0.7.52 — системный запрос установки обновления на Android

- **Экран разрешения установки теперь появляется.** Раньше после скачивания обновления приложение показывало «Разрешите установку приложений из этого источника», но системное окно так и не открывалось — запрос приходилось искать вручную. Причина: экран настроек запускался из фонового потока и не через текущую Activity, из-за чего на прошивках Tecno/HiOS, MIUI и похожих он молча не выходил на передний план.
- Если экран «Установка неизвестных приложений» на устройстве недоступен, приложение открывает «Сведения о приложении» (тумблер есть там) или показывает точный путь в настройках.
- Ошибки системного установщика больше не проглатываются — причина сбоя видна в интерфейсе.

Видимая версия Android совпадает с Windows: **0.7.52**. VersionCode 48.

Для полной синхронизации нужны **Windows 0.7.52** и **TerminalV Mobile 0.7.52** (VersionCode 48).
