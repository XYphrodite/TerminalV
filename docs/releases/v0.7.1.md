# TerminalV v0.7.1 — плоские сплиты без вложенности

## Изменено

- Дочерних сессий второй степени больше нет: сплит, который увёл бы панель глубже первого уровня, отклоняется целиком. Кнопки сплита и хоткеи гаснут на дочерних панелях — делить можно одиночную панель или первую панель корневого сплита.
- Все дочерние сессии относятся к одной родительской: A, B, C — всегда один уровень. Существующие вложенные раскладки не мигрируются, но глубже уже не уйти.
- Заодно выровнена отображаемая версия: `InformationalVersion` догнала `Version` (0.7.1).

## Проверки

- `ui/tests/pane-layout.test.js` + `chrome` + `tui-scroll` + `paste-file` + `write-chunk`: 30/30 pass; `node --check` чистый.
- Windows-сборка — через GitHub Actions при публикации тега.
