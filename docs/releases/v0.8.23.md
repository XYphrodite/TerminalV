# TerminalV v0.8.23 — удобный ряд цифр и защита от случайных нажатий в мобильном меню «Клавиши»

- Исправлено случайное срабатывание кнопок при прокрутке рядов в мобильной панели **«Клавиши»**: клавиша теперь отправляется только на `pointerup` при чистом тапе на месте и отменяется при сдвиге пальца (`pointermove` > 8px), прокрутке ряда (`scroll`) или перехвате жеста системой (`pointercancel`), при этом фокус терминала и экранная клавиатура остаются открытыми.
- Все 10 цифр (`1–9, 0`) в ряду цифр теперь равномерно умещаются по ширине экрана телефона без горизонтальной прокрутки (`flex: 1 1 0`), а прокручиваемые ряды `Esc / F1–F12` и `Tab–Del` используют `touch-action: pan-x` для плавного горизонтального свайпа.

```powershell
TerminalV update
```
