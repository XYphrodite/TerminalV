# TerminalV v0.7.32 — край экрана и отзывчивость сессии

- На Android убран отступ под вырез камеры сверху и слева. Отступ остаётся только снизу, когда открыта клавиатура. В альбомной ориентации телефон больше не показывает колонку списка сессий как на широком окне ПК.
- Ввод с телефона больше не ждёт ответа сети на каждый символ. Куски вывода, пришедшие вместе, рисуются одним обновлением.
- Открытие общей сессии больше не блокирует клавиши, пока уходит сохранённая история. Повторное подключение того же телефона две минуты не запускает `tailscale whois`.
- Видимая версия Android совпадает с Windows: **0.7.32**. VersionCode 28.

Для полной синхронизации нужны **Windows 0.7.32** и **TerminalV Mobile 0.7.32** (VersionCode 28).
