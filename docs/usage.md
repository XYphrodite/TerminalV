# Как пользоваться TerminalV

## Окно

Слева — список сессий, справа — терминал активной вкладки. Новая сессия открывается при запуске. Оболочка по умолчанию — PowerShell 7 (`pwsh.exe`), если его нет — Windows PowerShell.

Переопределить оболочку:

```powershell
$env:TERMINALV_SHELL = 'C:\Windows\System32\cmd.exe'
TerminalV
```

Первая сессия стартует из домашней папки; последующие новые вкладки наследуют рабочую папку активной сессии.

## Вкладки

- Кнопка **Новая вкладка** или `Ctrl+Shift+T`
- Клик по вкладке — переключение
- Перетаскивание вкладки мышью — изменить порядок вкладок
- Крестик, средняя кнопка мыши или `Ctrl+Shift+W` — закрыть
- Двойной клик по названию — переименовать, `Enter` сохранить, `Esc` отменить
- Неактивная вкладка с новым выводом помечается индикатором

При закрытии живой сессии появляется предупреждение с её названием и кнопками **Завершить сессию** / **Отмена**.
Крестик, средняя кнопка мыши и `Ctrl+Shift+W` используют одинаковое подтверждение; сочетание работает и при русской раскладке.
По умолчанию выбрана **Отмена**. `Esc` отменяет закрытие и возвращает фокус в терминал или в поле поиска, если оно было активно.

До подтверждения сессия продолжает работать. **Завершить сессию** закрывает только выбранную вкладку и останавливает её процессы; несохранённые данные могут быть потеряны.
Предупреждение показывается для любой живой сессии, даже если PowerShell просто ожидает команду. Уже завершённая сессия закрывается без предупреждения.
Если процесс завершился во время подтверждения, предупреждение отменяется, а вкладка остаётся с выводом и кодом завершения.

Закрытие всего окна по-прежнему сохраняет работающие фоновые сессии. Чтобы убрать вкладку, не останавливая процесс, используйте отдельное действие **Скрыть, оставив работать**. Подтверждённое закрытие крестиком именно завершает сессию.

## Управление сессиями

Нажмите **⋯** у вкладки или правую кнопку мыши по её названию. С клавиатуры: перейдите фокусом на строку вкладки и нажмите `Shift+F10`.

- **Группа проекта** — введите новое название или выберите существующее из подсказок. Пустое поле возвращает вкладку в раздел «Без группы». Пустые группы не показываются.
- **Цветовая метка** — пять цветов на выбор или «Без метки». Цвет отображается полоской у вкладки и сохраняется при переключении темы.
- **Закрепить вверху группы** — помечает вкладку звёздочкой и поднимает над остальными вкладками своей группы.
- **Сохранить** применяет настройки. **Отмена** и `Esc` оставляют всё как было.

Перетаскивание сохраняет порядок. При переносе на вкладку другой группы сессия получает её группу; закрепление также становится таким же, как у целевой вкладки, чтобы место вставки совпадало с видимым порядком. Новая вкладка наследует группу и текущую папку активной сессии, но не её закрепление и цвет. `Ctrl+Tab` и `Alt+1` … `Alt+9` следуют порядку открытых вкладок на экране и пропускают скрытые.

Поле **Найти сессию…** фильтрует список по названию и группе, без учёта регистра, включая кириллицу. `Enter` открывает первый результат; `Esc` сбрасывает фильтр и возвращает фокус терминалу. Фильтр не завершает и не скрывает сессии, а ввод в него не отправляется в PowerShell. Поиск текста внутри терминала остаётся отдельной функцией — `Ctrl+Shift+F`.

### Скрытые сессии

В диалоге **⋯** нажмите **Скрыть, оставив работать**. Настройки группы, цвета и закрепления при этом тоже сохраняются. Вкладка исчезнет из открытого списка, но её PowerShell и запущенные программы продолжат работать в фоне. Для уже завершённой сессии кнопка называется **Сохранить и скрыть**.

Кнопка **Скрытые · N** над списком показывает скрытые сессии; поле поиска работает и в этом списке. Нажмите на нужную строку или **↩**, чтобы вернуть вкладку с прежним процессом и выводом. Для завершения сначала верните вкладку, затем закройте обычным крестиком с подтверждением.

Можно скрыть все вкладки: новая оболочка автоматически не запускается. После закрытия и повторного открытия окна скрытые сессии сохраняются; TerminalV подключается к их прежним процессам, а не запускает копии. Скрытые терминалы продолжают принимать вывод, поэтому скрытие упорядочивает список, но не освобождает всю память их экранных буферов.

После перезагрузки Windows или завершения процесса остаётся сохранённый экран. При возвращении такой вкладки новая оболочка не запускается автоматически: для этого есть кнопка **Перезапустить**. Группы, метки, закрепление, порядок и видимость сохраняются в SQLite; старая база обновляется автоматически без удаления существующих вкладок.

## Клавиши

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+Shift+T` | Новая вкладка в папке активной сессии |
| `Ctrl+Shift+W` | Закрыть текущую вкладку |
| `Ctrl+Tab` | Следующая вкладка |
| `Ctrl+Shift+Tab` | Предыдущая вкладка |
| `Alt+1` … `Alt+9` | Вкладка по номеру |
| `Ctrl+C` | Копировать выделение (если есть), иначе сигнал прерывания в оболочку |
| `Ctrl+V` / `Ctrl+Shift+V` | Вставить |
| `Ctrl+Shift+C` | Копировать выделение |
| `Ctrl+Alt+C` | Копировать видимые строки отдельно, без пробелов по краям |
| `Ctrl+Shift+F` | Поиск по выводу текущей вкладки |
| `Ctrl+,` | Оформление |
| `Ctrl+B` | Свернуть / показать список сессий |
| `Ctrl+` `+` / `-` / `0` | Масштаб терминала, как в VS Code |
| `Ctrl` + колесо | Масштаб терминала |

Правый клик по терминалу: при выделении — копировать, иначе — вставить.

При вставке текста с переносами строк открывается предупреждение с предпросмотром и кнопками **Вставить в любом случае** / **Отмена**.
Это работает для `Ctrl+V`, `Ctrl+Shift+V` и правого клика; перенос строки в конце команды тоже требует подтверждения.
`Esc` отменяет вставку. После подтверждения вставляется текст, показанный в предпросмотре, даже если буфер обмена уже изменился. У длинных текстов предпросмотр сокращён; вставляется весь текст.

Если скопированные команды склеиваются с большими промежутками, выделите их и нажмите `Ctrl+Alt+C`.
Этот режим берёт строки прямо с экрана, убирает пробелы по краям каждой строки и сохраняет переносы и пустые строки.
Длинная команда, перенесённая на экране, тоже будет разделена на строки. Для кода с отступами или длинных команд используйте обычный `Ctrl+C` / `Ctrl+Shift+C` — они сохраняют отступы и склеивают автоматические переносы xterm.

## Поиск по выводу

Нажмите `Ctrl+Shift+F` или кнопку поиска слева вверху. Сочетание работает и при русской раскладке.
Панель появляется над терминалом и ищет текст в доступном буфере текущей вкладки, включая историю прокрутки. В полноэкранных TUI доступен только текст текущего буфера, а не исчезнувшие ответы приложения.

- Совпадения подсвечиваются, рядом с полем отображается номер выбранного результата и количество совпадений.
- `Enter` / `Shift+Enter` в поле поиска или кнопки `↓` / `↑` — следующее / предыдущее совпадение, с переходом по кругу.
- `Aa` включает учёт регистра. По умолчанию регистр не учитывается; специальные символы ищутся как обычный текст, не как регулярное выражение.
- `Esc` или крестик закрывают поиск и возвращают фокус терминалу. Переключение вкладки или открытие настроек также закрывает поиск.
- При новом выводе и изменении размеров результаты обновляются. Автоматический перенос длинной строки не разрывает искомое слово.
- Для отзывчивости интерфейса подсвечиваются первые 1000 совпадений; счётчик показывает `≥1000`, а переход между результатами доступен и за пределами этого лимита.

Ввод, вставка текста и сочетания клавиш внутри панели поиска не отправляются в оболочку. Текст запроса сохраняется между открытиями панели в пределах текущего запуска приложения, но не записывается в базу данных.

## Рабочая папка

После `cd` нажмите **Новая вкладка** или `Ctrl+Shift+T`: новая сессия откроется в текущей папке активного PowerShell. Сочетание работает в английской и русской раскладках. Поддерживаются пути с пробелами, кириллицей и буквальными квадратными скобками; переименование вкладки на путь не влияет.

Windows PowerShell 5.1 и PowerShell 7 сообщают путь при показе приглашения через [OSC 9;9](https://learn.microsoft.com/en-us/windows/terminal/tutorials/shell-integration). Интеграция подключается при запуске оболочки после обычных профилей, не меняя их файлы и внешний вид существующего приглашения. При явно заданной папке (наследование, восстановление, перезапуск) она выбирается после загрузки профилей. В первой сессии без сохранённого пути профиль по-прежнему может выбрать стартовую папку сам.

Последний известный каталог сохраняется отдельно от заголовка и экранного буфера, в том числе пока окно закрыто. Восстановление подключается к прежнему процессу и получает его актуальный путь; после перезагрузки Windows оболочка запускается в сохранённой папке. **Перезапустить** также использует последний известный каталог.

Если выбранная папка удалена или недоступна, сессия открывается в домашней папке, а над её терминалом появляется уведомление с кнопкой закрытия. Ввод оно не блокирует. Пока путь неизвестен, используется стартовая папка сессии. Внутри Muse и других запущенных программ, в провайдерах вроде `HKCU:` и в оболочках без такой интеграции остаётся последний известный файловый каталог. Если в уже открытой оболочке полностью переопределить функцию `prompt`, автоматическое обновление пути прекратится до запуска новой сессии.

После обновления старый фоновый процесс может продолжать обслуживать работающие сессии прежним кодом. В этом случае TerminalV показывает предупреждение: для включения отслеживания пути завершите нужные задачи и перезагрузите Windows. Простое закрытие окна сохраняет фоновый процесс и потому его не обновляет. TerminalV не завершает такие сессии автоматически и не отправляет в них команды установки интеграции.

## Если процесс завершился

На панели появляется код выхода и кнопка **Перезапустить**. Буфер экрана при этом сохраняется до рестарта.

## Оформление

`Ctrl+,` или шестерёнка слева открывает меню: тема (тёмные и две светлые), шрифт, размер, фото на фон сессий и его прозрачность. Список сессий сворачивается кнопкой `‹` или `Ctrl+B`.

Сессии живут в фоновом процессе `TerminalV.exe --host`. Закрытие окна не убивает vim, k9s и другой TUI — при следующем открытии вкладка подключается к тому же PTY. После перезагрузки Windows остаётся снимок экрана (включая alt-screen) в SQLite, оболочка стартует заново.

Полоса прокрутки терминала появляется, только если буфер не помещается, и окрашена в цвета текущей темы.

## Обновление

Установленная копия при запуске спрашивает GitHub. Если есть тег новее, слева появляется **Обновить**. Тот же механизм с командной строки:

```powershell
TerminalV update --check
TerminalV update
```

Команда идёт в консольный `TerminalV.com` (как `mining-fleet update`), а окно — это `TerminalV.exe`. PowerShell ждёт `.com` и возвращает приглашение. Открытое окно после установки закрывается и запускается заново.

Клик по `v…` внизу сайдбара повторяет проверку. Debug-сборка из `bin\Debug` / `bin\Release` не обновляется сама.

Без совпадения SHA-256, без `PK`/`MZ` и без ответа на `--help` файлы на диске не меняются.

Сборка 0.1.0 этого не умеет — поставьте 0.2.0 через `irm` один раз.

## Требования

- Windows 10 1809+ / Windows 11, x64
- Microsoft Edge WebView2 Runtime (обычно уже установлен)
