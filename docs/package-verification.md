## Найдено и исправлено

- Упаковка удаляла всю папку `artifacts`. Теперь создаётся свежий staging, а существующие архив/хеш не перезаписываются; есть `-OutputDirectory`.
- Обновление принимало ZIP без UI или COM. Обязательные файлы проверяются до замены EXE.
- Отложенное обновление не меняло `TerminalV.com`. Теперь COM применяется вместе с UI; ошибка замены возвращает UI и сохраняет возможность повторить попытку.
- Путь из повреждённого pending-маркера мог привести к перемещению и удалению посторонних файлов. Принимается только собственный каталог `.terminalv-update-<GUID>/payload`; недопустимый маркер удаляется без обращения к указанному им пути. Junction/symlink не допускаются при применении и рекурсивной очистке.
- Ошибка публикации pending-маркера теперь откатывает EXE. Маркер записывается атомарно; повторная установка поверх ожидающего обновления запрещена.
- Проверка запуска читает оба потока вывода и завершает дочерний процесс при отмене.

Регрессии воспроизводят неполный пакет, неверный хеш, сломанный EXE после замены, ошибку записи маркера, заблокированный COM, повторное обновление, посторонний путь в маркере и похожие на служебные имена пользовательских каталогов. Реальные junction/symlink и принудительное прерывание питания отдельно не моделировались.

## Повторение

Из корня репозитория, с новым каталогом для каждой сборки:

```powershell
.\scripts\publish.ps1 -OutputDirectory artifacts\candidate-02
$env:TERMINALV_TEST_PWSH = 'C:\Repos\TerminalV\artifacts\powershell-test-7.6.6\runtime\pwsh.exe'
.\scripts\verify-package.ps1 -Package artifacts\candidate-02\TerminalV-win-x64.zip
```

Путь к portable PowerShell задаётся только при необходимости; без PowerShell 7 соответствующие ConPTY-проверки явно пропускаются. В зафиксированном выше прогоне он был доступен.

## Чеклист на момент предварительного прогона

- [ ] В отдельной учётной записи Windows или VM открыть обычное WPF/WebView2-окно и вручную проверить физические EN/RU-сочетания, многострочный буфер обмена, Muse/TUI, панели и восстановление после закрытия окна.
- [ ] Там же проверить обновление реальной старой установки с открытыми окнами, перезапуск GUI и сохранение фоновых сессий. Рабочую установленную копию пользователя этот прогон не затрагивал.
- [ ] Учесть старый фоновый хост: новые профили и интеграция каталога могут требовать сохранения работы и перезагрузки Windows, как описано в руководстве.
- [ ] По отдельной команде подготовить коммит, новый номер версии, повторно собрать/проверить пакет и выполнить push/релиз.
